# 大跌定投时间线推演框架

**起源：** 2026-07-13用户问「预计什么时间会有带血的筹码给他，市场先生」——需要预判恐慌演进的节奏来决策定投时机。

## 核心逻辑

下跌不是一次到位的，恐慌是有层级地递进的。大跌定投的子弹是有限的（每月每标的2次），需要用时间线推演来决定「哪一枪打在哪一波」。

## 三层递进框架

### 第一天：跟随性恐慌
- 特征：受外部冲击（韩国崩盘、美股大跌）拖累，A股跟跌
- 跌幅：-3%~-5%
- 应对：大跌定投第一枪可以打，也可以看情况等
- 关键变量：当晚美股表现

### 第二天：情绪宣泄
- 特征：如果美股连跌，A股低开；如果美股企稳，A股可能V回来
- 跌幅：-2%~-4%
- 应对：如果是低开且跌幅>5%，第二枪该打了
- 关键变量：恐慌是否蔓延到防御品种（茅台/宁德/银行）

### 第三天及以后：真正的带血筹码
- 特征：防御品种开始补跌，融资盘爆仓，散户熬不住割肉
- 跌幅：累计-10%+
- 应对：条件单的深调档位（1.25/1.18/1.10）开始发挥作用
- 关键变量：融资余额是否下降

## 输出格式

### 「什么时候有带血的筹码」时间线表

```
预计恐慌演进路线

今天（周一）：韩国崩9%，A股跟跌 → 跟随性恐慌
今晚（美股）：决定明天走势
  绿→美股平/涨 → 明天反弹
  黄→美股跌-1~2% → 明天低开V回
  红→美股跌-3%+ → 真正的恐慌开始

芯片买入路线图：
价位     距现价   触发条件
1.356    -2.4%    大跌定投-5%触发    🩸 新鲜筹码
1.30     -6.5%    前低支撑区          🩸🩸 开始带血
1.25     -10%     条件单T1           🩸🩸🩸 带血筹码

```

### 核心原则
1. 预期「今天不是最带血的时候」— 防御品种（建行/红利）还在涨时，不是真正的恐慌底
2. 子弹留一发给最恐慌的时刻 — 每月2次额度不要在同一天打完
3. 条件单是最后的保险 — 最深的恐慌由条件单（1.25/1.18/1.10）来接
4. 盯美股 — 美股止损是关键变量，决定恐慌的持续性
