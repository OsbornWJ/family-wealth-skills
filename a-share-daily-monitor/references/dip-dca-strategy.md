# 大跌定投策略 (Dip DCA) — 双触发机制

> 2026-07-10 新增，2026-07-14 升级为双触发（单日+累计）。
> 补充条件单的盲区——当市场跌幅不够深、条件单无法触发时，通过固定阈值的跌幅定投抓住回调机会。

## 起源

2026-07-10 实战回测发现条件单设太低、牛市不给机会。2026-07-14 又发现单日阈值漏掉了"连续阴跌"型回调（AI ETF 从7/9到7/14累计跌-9.2%，但单日从未突破-5%阈值），因此升级为双触发。

## 双触发机制

**两条检查线，任一触发即通知执行：**

### 线1：单日触发
当日涨跌幅 < threshold%（基于昨收）

### 线2：累计触发（2026-07-14新增）
当日收盘价 / 近5个交易日中最高收盘价 - 1 < threshold%

**核心逻辑：** 单日触发抓"急跌"，累计触发抓"阴跌"。两个互补，共享月度2次额度。

## 现金预算管理

基于总可支配现金计算：

```
1. 可用现金 × 60% = 定投资金池，40%留作安全垫+条件单备用
2. 按置信度权重分配各标的：芯片35% | AI 30% | 创新药20% | 军工15%
3. 每月满打满算预算上限 = ¥18,000
4. 每月1日重置所有标的的触发计数和预算
```

## 执行流程

```
每个交易日尾盘检查（最晚14:50）
  ↓
对每个标的：
  检查①：单日涨跌幅 < 阈值？（基于昨收）
  检查②：(收盘/5日最高收盘-1) < 累计阈值？
  ↓
任一条件满足 + 本月触发次数 < 2次
  ↓
通知用户：标的 + 触发类型（单日/累计）+ 现价 + 建议金额
  ↓
用户确认 → 执行买入 → 更新计数
```

## 与条件单的关系

两层并行，不冲突：
- 🔴 条件单：深调抄底（固定价格，如AI 1.10）
- 🟢 大跌定投：抓中等跌幅+连续阴跌（双触发）

## 重要教训

1. **定投触发应机械执行，不因外部恐慌跳过。** A股对外部冲击抗跌性强（如韩国崩盘未传导），过度谨慎反错过买点。
2. **双触发必要性的案例：** AI ETF 7/9→7/14累计跌-9.2%，但单日从未破-5%。旧规则会完全漏掉。
3. **用户否决后次日市场企稳，应提醒补执行。**
