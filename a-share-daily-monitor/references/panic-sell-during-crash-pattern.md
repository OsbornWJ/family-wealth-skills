# 急跌恐慌卖出模式 — 应对流程

## 触发场景

科技板块单日暴跌（科创50 -5%+ / 持仓ETF -6%+），用户说「开始震荡了，是不是应该止盈落袋」「今天卖不卖」等。

## 典型对话序列（2026-07-02 实战）

```
用户: 开始震荡了 我的科技是不是应该止盈落袋
回答: 不卖。而且今天卖是错上加错。
理由: 今天跌7%的时候卖，卖在最低点。
      等反弹再卖也不迟。如果真的见顶，会给你多次冲高机会让人跑。
      一天跌完就再也不回头的情况极少。

用户: 那我要改第一档加仓吗，下调？
回答: 不建议下调。
理由: 当初设1.17的时候，是因为觉得那是合理的加仓价格。
      现在市场正要到那个价格了，你却想把它调低——这是情绪在驱动决策，不是逻辑。
      条件单的意义是让恐慌的时候还能按纪律执行。
```

## 判断框架

### 第一步：先看利润垫，再讨论操作

```
AI   成本0.51 → 现价1.18 → 还有+130%
芯片 成本0.45 → 现价1.41 → 还有+212%
```

如果利润垫 > 100%，跌6-8%根本伤不到本金。**讨论止盈之前先展示这个数据。**

### 第二步：检查条件单是否即将触发

```
AI第一档1.17 → 现价1.18 → 差-1%
如果下调到1.10 → 需要再跌-7%才能触发 → 如果是正常回调根本到不了
```

用户想下调条件单是因为怕继续跌——但条件单存在的意义就是让系统在恐慌时自动执行。**下调=破坏纪律。**

### 第三步：检查系统性信号

三个信号判断是技术回调还是阶段见顶：

| 信号 | 短期休整 | 阶段见顶 |
|:----|:--------|:---------|
| 量能 | 缩量回调（AI 270万手 vs 前日428万手） | 放量暴跌 |
| 上证50 | 没跟跌，大蓝筹稳定 | 大票也开始跌 |
| 资金流向 | 轮动到医药/红利，非离开市场 | 全市场一起崩 |

**2026-07-02关键信号：上证50也跌了-2.44%** — 前两天都是"科技跌、大票不动"，今天大票也开始跟着跌。这是更高级别的系统性风险信号，需要更谨慎。但即便如此，$139K现金不急着打出去是对的。

### 第四步：如果用户坚持要卖

```
要卖也是等反弹到1.27-1.30（AI）或1.53-1.60（芯片）再考虑卖一部分锁利，
不是今天恐慌出逃。
```

## 输出格式

```
**不卖。** 而且今天卖是错上加错。

### 为什么今天不卖
XX  -X%  今天跌这么多
YY  -Y%  今天跌这么多
你说要落袋——今天卖就是跌了X%的时候卖，卖在最低点。

### 你的利润垫
XX   成本X.XX → 现价X.XX → 还赚+XXX%
YY   成本X.XX → 现价X.XX → 还赚+XXX%

### 思考框架
如果今天卖了，它明天企稳、下周又涨回到原位，你是追还是不追？

让条件单工作，不要让情绪工作。
```

## 禁忌

- ❌ 不要在用户恐慌时输出长编大论的分析报告——用户要的是「卖不卖」的yes/no + 一句话理由
- ❌ 不要用「我理解你的感受」开头——用户不需要共情，需要数据
- ❌ 不要建议用户「那你可以卖一半」——这会鼓励恐慌性操作
- ✅ 直接说「不卖。理由如下：」——然后用关键数据（利润垫、条件单位置、系统性信号）快速说服
