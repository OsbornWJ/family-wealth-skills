# 小仓位实验仓评估框架

## 场景

用户持有极少量某标的（如三一重工200股=¥3,346，占总资产1.5%），浮亏10%+，想是否补仓。核心矛盾：**金额太小，补不补对账户无本质影响，但用户想确认「要不要继续这个实验」**。

## 四步诊断流程

### 第一步：量化影响

```
持仓200股 × 现价16.73 = ¥3,346
占总资产: 1.5%
即使全部亏光: 损失0.3%总资产
即使补200股: 耗资¥3,346，仓位升至3%
```

**如果两轮补仓后仓位依然<5%，这件事对账户整体没意义。** 先让用户知道这个标的不值得花太多精力。

### 第二步：检查实验进展

- 买入价 vs 现价：证明实验假设目前是错的
- 买入理由还在吗？（如基建周期回暖、设备更新政策、业绩改善）
- 当前是**周期底部**还是**下降通道**？

### 第三步：与现有现金部署机会对比

```
其他现金去处对比：
军工ETF  1.298 → 距1.30突破位+0.15%
创新药   0.866 → 距补仓区间0.85-0.86
建行     9.53  → 股息率4.08%
红利     0.569 → 被抽血，但等轮动
```

如果其他方向赔率更清晰，优先补充逻辑强的仓位，而非摊小小实验仓的成本。

### 第四步：结论输出

#### 如果用户有明确逻辑（看好基建周期/公司基本面）：

```
逻辑成立，补200-300股做仓位配置。
补仓后成本降至约¥17.70，3%止损位设在¥15.90。
这个仓位当板块配置的一小块，不指望它扛大梁。
```

#### 如果用户只是看跌多了想摊（最常见情况）：

```
不建议补。理由是：
1. 这200股在组合里没有战略角色
2. 补仓理由是「跌了」不是「要涨」
3. 现金留着补军工/创新药，赔率更清晰
4. 真想走基建线，换基建ETF比单股安全
```
