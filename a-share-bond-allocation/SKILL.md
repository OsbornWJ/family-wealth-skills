# A股债券/固收配置

**IPS：** 与 `family-wealth-ips` 钱池表一致。家庭固定资本默认走储蓄国债/短债；本 skill 提供工具细节，「能不能买」仍由 family-wealth-ips 把关。

## 触发条件
用户问：纯债能买吗、债基/固收+影响、债券ETF、储蓄国债/定存、利率怎么看、钱放哪停靠、清仓款买什么。注：管"股息率/红利股"的问题走 `a-share-dividend-allocation`，本技能管"债"。

## 第一步永远是：这是哪笔钱？(2026-09 用户纠正)
用户有两笔以上的钱，**先对号入座再分析**。判断错钱池，整个建议就错——本技能诞生的那次会话，我先按"交易弹药"答(等FOMC别买长债)，用户纠正"是家庭固定资本（配偶共有本金）/家庭固定资本"，目标函数完全不同：

| 钱池 | 目标函数 | 回撤容忍 | 正确工具 |
|:---|:---|:---:|:---|
| 交易弹药(自管现金，等FOMC/回调出手) | 效率出手 | 可接受 | 现金/货基/短债；距出手<1周则别买 |
| **家庭固定资本(家庭固定资本（配偶共有本金）)** | **保本 > 锁息 > 增益** | **≈0(本金零容忍)** | **储蓄国债锁息为核心底仓 + 短债做流动层** |
| 蓄水池(招商双债/平安瑞尚等已持债基) | 现金停靠 | <1% | 维持现状，不加仓 |

## 利率环境判断(数据工作流)
1. 长端位置：`ak.bond_zh_us_rate()` → `中国国债收益率10年`，算全历史分位 `(y10 < cur).mean()*100`。2026-09实测：1.68% = **1.6%分位(历史地板)**，上周刚创 1.596 新低。全历史区间约 [1.60, 5.41]
2. 政策锚：`ak.macro_china_lpr()`(2026-08: 1Y 3.0 / 5Y 3.5)。**中国宽松周期与美联储加息是两条独立曲线**——不要用美国加息预期直接推中国债市方向
3. 债市赚钱效应：Sina K线拉 sh511010(国债ETF 5-7Y) / sh511260(十年国债ETF) / sh511360(短融ETF, T+0)
4. 基金真实回报：`ak.fund_name_em()` 按 基金类型 筛 `债券型-中短债/债券型-长债` → 挑头部 → `fund_open_fund_info_em` 拉净值 → 年化 + 近1年最大回撤

## 框架规则(2026-09 验证)
1. **利率历史地板位(10Y<2%)不追长纯债/国债ETF**：票息1.7%覆盖不了久期风险。久期8Y × 反弹30bp ≈ 净值-2.4%；债灾级别曾-15%(华夏纯债2016)。实测对比：长纯债年化2.57%/回撤可深 vs 短债1.72%/回撤0.05%——差额买的是风险
2. **储蓄国债 = 固定资本核心**：电子式储蓄国债约每月10号发行窗口；票息 ≈ 同期限记账式国债 + 40~60bp(2026-09推算 3Y~1.9% / 5Y~2.1%，**必须标注"以财政部当期公告/银行柜面为准"**，akshare无此数据不可编数)；利率低位"锁短不锁长"(3Y优先，留2027后利率回升的再配置空间)；电子式每年付息优于凭证式一次还本
3. 短债基金 A 类(持7天免赎回费)做流动层；**期限>3个月选A不选C**(C类天天扣销售服务费)；场内停靠用短融ETF 511360(T+0)，比场外赎回灵活
4. **选产品必须看真实净值，名字不可信**：同为"短债"，广发安泽短债A(002864)近1年 **-4.61%/回撤-4.9%** vs 中欧短债A(002920) +1.72%/回撤-0.05%——"短债=安全"是错觉。嘉实超短债C(070009)年化仅0.36%，已不如货基
5. 收益率新低后小幅反弹属正常——判断"债牛尾部"看：收益率分位<5% + 国债ETF走平(近1月<0.2%) + 近1月新低后反弹

## Pitfalls
- `fund_open_fund_info_em` 净值日期是字符串；`bond_zh_us_rate` 数据点稀疏非每日——窗口计算用**日历**偏移不要用行数偏移
- 场内ETF价格为未复权价：分红除息压低涨幅读数(511010 近1年价格+0.0%≠总回报)。收益对比优先用场外基金净值(含分红)或标注未复权
- 定存/大额存单利率无直接接口：给推算区间并标注"以柜面为准"
- 用户问配置时若无钱池信息，默认按最大可能先给框架+让用户对号入座，不要默认"都是我的弹药"——用户反感反复追问，给分层框架比问三遍强
