# 护盘行情分析框架

## 起源

2026-07-21/22用户连续两天看到上证50+1.5%但持仓科技跌-3%，发出「6 大盘开始表演了」「护盘没啥用，继续阴跌」的判断。需要区分「真见底」和「假护盘」。

## 核心原则

上证50涨不等于市场见底。护盘资金只拉银行/保险/石油等权重，科技/小盘继续跌。只有科创50放量止跌才是真信号。

## 诊断三步

### 第一步：计算分化度

```python
分化度 = 上证50涨跌幅 - 科创50涨跌幅
# >2% = 极端分化，护盘行情
# 1~2% = 轻度分化
# <1% = 正常市场
```

### 第二步：建行/红利是否在涨

- 建行涨+红利涨/平 = 资金在银行避险，不是护盘资金托市
- 建行涨+红利跌 = 纯护盘拉指数，不可持续
- 建行跌+红利跌 = 全面恐慌，防御崩了

### 第三步：结论

| 信号组合 | 诊断 | 操作 |
|:--------|:----|:----|
| 分化度>2% + 建行涨 + 科技跌 | 护盘假象 | 不动，条件单挂着等科技自愈 |
| 分化度<1% + 科技止跌 | 市场自然见底 | 考虑按DCA执行 |
| 建行/红利开始跌 | 防御松动 | 接近恐慌，准备DCA |

## 输出格式

```
### 护盘行情诊断
上证50: +X.XX% | 科创50: -X.XX% | 分化度: X.X% → 🔴极端分化
建行: +X.XX% | 红利: +X.XX% → 资金在银行避险

结论：护盘假象，科技还在流血。条件单挂着等自愈。
不要因为上证50涨就以为市场见底了。
```

## 历史参照

用户问「是不是重演去年」——2025年特征是上证50护住不跌，科技阴跌半年，最后权重补跌才见底。今年的区别：外盘强（港股涨）、汇率稳、经济没恶化。跌幅可能不如去年深，但磨底时间可能类似。

## 救市利好定性

用户问「400亿救市？很多吗？它卖出都卖不少呢」——利好有效性分析：

| 对比项 | 金额 |
|:------|:----:|
| A股全市场日均成交 | ~1.2万亿 |
| 利好金额 | XXX亿 |
| 占比 | X.X% |

定性：信号意义大于实际金额。说明上层开始关注，但不足以扭转趋势。
操作影响：零。DCA和条件单策略不需要调整。
