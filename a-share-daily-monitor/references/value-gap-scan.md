# 价值洼地扫描 — 组合缺口分析

当用户问「下一个有价值的洼地是什么」「钱该往哪放」「还有什么可以买的」时，这个流程找到用户现有组合之外的低估/对冲机会。

**与 `industry-scan.md` 的区别：** 行业扫描是「全市场谁跌最多」，价值洼地扫描是「我的组合缺什么」。出发点不同，结论也不同。

## 三步流程

### 第1步：分析用户已有组合的结构性特征

| 维度 | 检查 | 典型结论 |
|:----|:-----|:--------|
| 风格暴露 | 成长/价值/周期/防御各自占比 | 科技偏重，缺防御/周期 |
| 地域暴露 | A股/H股/美股 | 全部A股，缺海外 |
| 相关性 | 持仓之间的涨跌相关系数 | 科技股同涨同跌 |
| 规模暴露 | 大盘/中盘/小盘 | 以ETF为主，缺个股alpha |
| 宏观对冲 | 是否有利率/通胀/地缘相关资产 | 缺黄金/商品/债券 |

### 第2步：对比全市场数据找滞涨板块

来源：申万行业今日涨跌 + 近20日涨幅（东财 push2 API）

```
数据源:
url = 'https://push2.eastmoney.com/api/qt/clist/get'
params = {'pn':1,'pz':31,'po':1,'np':1,'fltt':2,
          'fields':'f2,f3,f4,f12,f14,f104,f105',
          'fs':'m:90+t:2+f:!50'}
f3=今日涨跌, f104=近20日涨幅, f105=近60日涨幅
```

筛选条件：
- 近20日涨幅 < 市场均值（对标上证/科创50）
- 近60日跑输大盘的板块
- 今日无暴跌（跌幅<3%）

### 第3步：缺口匹配 — 每只候选回答两个问题

| 候选 | 我的组合缺它吗？ | 现在买赔率好吗？ | 结论 |
|:----|:---------------:|:----------------:|:----:|
| 黄金 | ✅ 无宏观对冲 | ✅ 距60日低点+3.5% | 🥇 最佳缺口填补 |
| 中概互联 | ✅ 无海外科技暴露 | ✅ 仍在亏损中 | 🥇 性价比最优 |
| 军工 | ❌ 已持仓深套 | ❌ 趋势未反转 | ❌ 不是缺口，是仓位 |
| 保险 | ✅ 无金融股 | 🟡 近20日+5%没涨 | 🥈 可考虑但非紧急 |

## 输出格式

```
## 🎯 价值洼地分析

### 你的组合现状
- 科技偏重（芯片/AI/创新药 = ~XX%）
- 防御有（红利/建行 = ~XX%）
- 缺宏观对冲，缺海外科技，缺周期股

### 候选排名
🥇 黄金/XXX — 填补XX缺口，距60日低点+X%，赔率X:X
🥈 中概互联/XXX — 填补XX缺口，成本还亏X%，赔率X:X
❌ 军工/XXX — 不是缺口，已持仓+趋势未反转

### 一句话建议
现在最值得买的不是涨最多的，而是你组合里没有的。
```
