# 演示对话（示例组合 + 实跑报告）

数字与持仓均为 **示例**，请勿当作投资建议。

完整脚本实跑（2026-09-11）：  
→ [scenario-monitor-2026-09-11.zh.md](./scenario-monitor-2026-09-11.zh.md)

---

**用户：** 手上大约 5 万现金，想做收息，现在能买银行吗？

**Agent（`family-wealth-ips`）：**

```
能不能买: 先别买（还缺信息）
这是哪笔钱: 还没确认 —— 自己炒股的钱，还是家里保本的钱？
应急金 / 股票类仓位: 要看家底表后再算
接下来: 先确认「哪笔钱」，再谈买什么
```

---

**用户：** 是自己炒股的钱，应急金大概 8 个月，股票类大概 22%。

**Agent：**

```
能不能买: 可以
这是哪笔钱: 自己炒股的钱
应急金: 大约 8 个月（≥6）✓
股票类: 约 22% / 上限约 30%；收息层一般不抬高股票风险仓
接下来: → a-share-dividend-allocation（先拉实时价再列表）
```

---

**用户：** 顺便跑一下监控，今天跌了还要不要加芯片？

**Agent（`a-share-daily-monitor`）：**  
跑 `morning_check` / `pre_close_check` / `daily_monitor`，把报告贴进对话。

```
上证 3888 (-1.18%) | 科创50 -1.01% | 两市约 1.97 万亿（黄灯）
芯片市价约 1.022（-1.35%），距配置峰值约 -5.4%
早盘/尾盘硬警报: 0 | 日报触发: 无
折溢价: 芯片约 -1.5%（相对 09-10 净值）
```

```
能不能买: 先别买（或先少买点）
依据: 偏弱缩量日 + 破 20MA；未触发硬止盈，也没有进攻信号
若试仓: 原计划 1/3～1/2，并写清止损
```
