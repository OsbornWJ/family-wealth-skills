# FOMC周 + 技术确认 = 最佳买入窗口

## 核心原则

当同时存在两个独立的事件时——**宏观催化剂**（FOMC/CPI/非农）和**技术确认信号**（3日站上MA10/回踩不破前低）——不要单独看待其中任何一个，而是让两者交汇：**技术确认在前，宏观落地在后，两个条件同时满足再执行。**

## 典型案例（2026年6月创新药ETF）

```
6/12（周五） Day 1 ✅ 收0.776站上MA10(0.775) 
6/15（周一） FOMC周开始，市场偏谨慎，Day 2观察日
6/16（周二） FOMC Day 1，Day 3确认日
6/17（周三） FOMC决议落地 ← 最佳买入窗口
```

## 逻辑

1. **技术确认先行** — 3日站上MA10证明短期趋势从下跌转为震荡/上行，不是一日游反弹
2. **宏观落地收尾** — FOMC落地前资金观望，落地后方向明确。如果偏鸽→科技涨，你已确认趋势；如果偏鹰→市场跌，你因等待没买在最高点，可能更低接
3. **两个条件不冲突** — 3日确认通常需要2-3个交易日，FOMC是周二三，时间窗口刚好重合

## 输出格式

当用户询问加仓时机且FOMC临近时，直接输出时间线对照表：

```
周五(6/12)  Day 1 ✅ 收X.XX 站上MA10(X.XX)
周一(6/15)  Day 2   确认日，FOMC前资金偏谨慎
周二(6/16)  Day 3   FOMC第一天，等结果
周三(6/17)  FOMC决议落地 ← 最佳买入窗口
```

**操作建议：** 周二收盘确认趋势后，周三开盘动手。条件单设在技术支撑位（如MA5附近），开盘执行。
