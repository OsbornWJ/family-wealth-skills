# 实跑示例：偏弱震荡日复盘（2026-09-11）

> **说明**  
> - 对公开包 `portfolio.example.json` **实跑**生成（腾讯/新浪行情 + AKShare）。  
> - 标的名为「示例-*」，成本/峰值为演示配置，**不是**真实账户。  
> - 采集于 **2026-09-11 收盘后**（报告时间戳可能显示晚间；价格为当日收盘）。  
> - 不构成投资建议。

复现：

```bash
cd a-share-daily-monitor
python3 scripts/morning_check.py
python3 scripts/pre_close_check.py
python3 scripts/daily_monitor.py
```

---

## 场景

**用户：** 今天跌了，按示例组合跑早盘、尾盘、日报。芯片还要不要加？

**Agent：** 先贴脚本全文，再按 `family-wealth-ips` 给「能不能买」。

**读表：**

| 列 | 含义 |
|----|------|
| 成本盈亏 | 相对 `portfolio` 的 cost |

## 4）能不能买（示例回答）

假设：自己炒股的钱，应急金约 8 个月，股票类约 22% / 上限 30%。

```
能不能买: 先别买（或先少买点）
这是哪笔钱: 自己炒股的钱
应急金: 约 8 个月 ✓
股票类: 约 22%，空间有，但今天偏弱

依据:
- 上证/科创约 -1%，两市成交 1.97 万亿偏冷
- 芯片破 20MA，相对配置峰值约 -5%，无硬警报也无放量企稳
- 折溢价小幅折价，不是加仓信号

建议: 默认不加芯片；若执意试仓，用原计划 1/3～1/2 并写清止损
```
