# A股 DCF 估值模型

## 适用场景

**使用：** 需要对个股做绝对估值、判断内在价值、与当前股价比较安全边际
**禁用：** 银行/保险（用DDM替代）、周期股高点（用PB替代）、亏损股（PE/PB框架优先）

---

## ⚠️ 核心原则

1. **公式优于硬编码** — 所有预测值必须是变量计算，不是手动填数
2. **分步验证** — 每完成一步展示给用户确认，不要一次性端出整张表
3. **数据溯源** — 每一个输入参数标注来源（AKShare/年报/巨潮）
4. **情景思维** — 永远做 Bear/Base/Bull 三个情景

---

## 十步建模流程

### Step 1: AKShare 数据采集

```python
import akshare as ak

# 历史财务数据（近5年）
df_income = ak.stock_financial_report_sina(stock="600519", symbol="利润表")
df_bs = ak.stock_financial_report_sina(stock="600519", symbol="资产负债表")
df_cf = ak.stock_financial_report_sina(stock="600519", symbol="现金流量表")

# 当前股价与估值数据
df_rt = ak.stock_zh_a_spot_em()  # 实时行情（取最新收盘价）
df_val = ak.stock_a_lg_indicator(symbol="600519")  # 含PE/PB/估值分位

# 历史财务指标（用于趋势判断）
df_hist = ak.stock_financial_abstract_ths(symbol="600519")

# 无风险利率（中国10年期国债收益率）
# 可通过 ak.bond_china_yield() 获取
```

**验证清单：**
- [ ] 营收/净利润数据与连续5年年报一致
- [ ] 每股收益检查（EPS = 归母净利润 / 加权股本）
- [ ] 当前股价为最新收盘价
- [ ] 总股本确认（注意A股总股本 vs 流通股本）

### Step 2: 历史财务分析（5年）

| 指标 | Y-4 | Y-3 | Y-2 | Y-1 | LTM | 趋势判断 |
|:---|:---|:---|:---|:---|:---|:---|
| 营收(亿) | | | | | | |
| 营收增速 | | | | | | 加速/放缓/稳定 |
| 毛利率 | | | | | | |
| 净利率 | | | | | | |
| 经营现金流(亿) | | | | | | |
| 资本支出(亿) | | | | | | |
| 自由现金流(亿) | | | | | | |

**关键计算：**
- 营收CAGR（近3年）= (最新营收/3年前营收)^(1/3) - 1
- 平均毛利率 = 5年毛利率均值（排除异常年）
- 经营现金流/净利润比率 = 衡量盈利质量（>1为优秀，<0.7需警惕）

### Step 3: 营收预测（5年 三情景）

```
BEAR（保守） → BASE（基准） → BULL（乐观）
```

**增长率衰减模式（以BASE为例）：**
| 年份 | Y+1 | Y+2 | Y+3 | Y+4 | Y+5 |
|:---|:---|:---|:---|:---|:---|
| 营收增速 | 近期可见增速 | 逐步收敛 | 行业均值 | 接近GDP | 终端增速 |
| 示例(茅台) | 15% | 12% | 10% | 8% | 5% |

**增速设定原则（A股语境）：**
- 终端增长率（Terminal Growth）= 中国GDP增速预期（2.5%-3.5%）
- 高速增长期增速 ≠ 历史均值（注意边际递减效应）
- Bear = Base × 0.7，Bull = Base × 1.3（经验法则）

### Step 4: 利润表预测

```
营收(预测) = 上年营收 × (1 + 增长率)
- 营业成本 = 营收 × (1 - 毛利率)
= 毛利润
- 销售费用 = 营收 × 销售费用率%（取历史均值）
- 管理费用 = 营收 × 管理费用率%
- 研发费用 = 营收 × 研发费用率%
= 营业利润
- 所得税 = 营业利润 × 税率%（实际税率，非名义）
= 净利润(NOPAT近似)
```

**注意：** A股利润表中营业税金及附加、资产减值损失等行业特性项需单独处理

### Step 5: 自由现金流(FCF)计算

```
NOPAT = 营业利润 × (1 - 税率)
+ 折旧摊销（非付现成本）
- 资本支出（CapEx）
- 营运资本增加（Δ NWC）
= 自由现金流(FCFF)
```

**A股特定处理：**
- 折旧摊销 ≈ 固定资产折旧+无形资产摊销+长期待摊摊销（现金流量表获取）
- CapEx ≈ 购建固定资产/无形资产支付的现金
- Δ NWC ≈ (流动资产-货币资金) - (流动负债-短期借款) 的年度变化
- 税率：取实际综合税率（所得税费用/利润总额），非25%名义税率

### Step 6: WACC 计算（A股版）

```
WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)
```

#### Ke（权益成本）—— CAPM模型（A股）

```
Ke = Rf + β × ERP

Rf = 中国10年期国债收益率（~2.5%-3.0%）
    → ak.bond_china_yield() 获取
β = 个股近5年月度beta（相对沪深300/上证指数）
    → 可用历史收益率回归计算
ERP = 股权风险溢价（A股通常取6%-7%，vs 美股5%-5.5%）
    理由：A股波动率更高，散户占比高
```

#### Kd（债务成本）

```
Kd = 利息支出 / 平均有息负债余额
   = 财务费用中的利息支出 / [(期初短期借款+长期借款+应付债券+期末...)/2]

或简化：取同期LPR（1年期LPR ~3.1%）
```

#### 资本结构

```
V = E + D
E = 总市值（股价 × 总股本）
D = 有息负债 - 货币资金（净债务概念）

有息负债 = 短期借款 + 长期借款 + 应付债券 + 一年内到期的非流动负债
```

**WACC 典型范围（A股）：**
| 类型 | WACC范围 |
|:---|:---|
| 大蓝筹（茅台/招行等） | 7%-9% |
| 一般制造业 | 9%-11% |
| 高成长科技股 | 11%-14% |
| 小盘/亏损股 | 不适用DCF |

### Step 7: 现金流折现

**年中折现惯例：**
- Year 1 折现因子 = 1 / (1 + WACC)^0.5
- Year 2 折现因子 = 1 / (1 + WACC)^1.5
- 以此类推

```
PV(FCF_n) = FCF_n × Discount_Factor_n
```

### Step 8: 终端价值(Terminal Value)

**永续增长法（首选）：**
```
TV = FCF_5 × (1 + g) / (WACC - g)
PV(TV) = TV / (1 + WACC)^4.5
```

**g的选取：**
- 保守：2.0%（低于GDP增速）
- 基准：2.5%（GDP增速预期）
- 乐观：3.0%（仅龙头公司）
- **严禁：** g > WACC（无限价值）
- **严禁：** g > 5%（脱离经济常识）

**终端价值占比检查：**
- 正常：PV(TV)占EV的50%-75%
- 若>80%：模型过度依赖终端价值假设，需调整
- 若<40%：终端价值假设可能过于保守

### Step 9: 股权价值桥接

```
+ 预测期FCF现值之和      = XXX 亿
+ 终端价值现值            = YYY 亿
= 企业价值(EV)           = ZZZ 亿
- 净债务(净债务=有息负债-货币资金) = AAA 亿
+ 长期股权投资(如适用)    = BBB 亿
= 股权价值                = CCC 亿
÷ 总股本                  = DDD 亿股
= 每股内在价值            = ¥EEE.EE

当前股价                  = ¥FFF.FF
安全边际                  = (EEE - FFF) / FFF
```

### Step 10: 敏感性分析（三张表）

**表1：WACC × 终端增长率**
```
         g=2.0%   g=2.5%   g=3.0%   g=3.5%
WACC=7%   ¥150     ¥165     ¥185     ¥210
WACC=8%   ¥130     ¥140     ¥155     ¥175
WACC=9%   ¥110     ¥120     ¥130     ¥145  ← 基准格
WACC=10%  ¥95      ¥105     ¥115     ¥125
WACC=11%  ¥80      ¥90      ¥100     ¥110
```

**表2：营收增速 × 净利率**
```
         净利率50%  52%  54%  56%  58%
增速5%     ¥XX      ¥XX  ¥XX  ¥XX  ¥XX
增速10%    ¥XX      ¥XX  ¥XX  ¥XX  ¥XX  ← 基准格
增速15%    ¥XX      ¥XX  ¥XX  ¥XX  ¥XX
增速20%    ¥XX      ¥XX  ¥XX  ¥XX  ¥XX
增速25%    ¥XX      ¥XX  ¥XX  ¥XX  ¥XX
```

**表3：β × ERP**
```
         ERP=5%   6%   6.5%  7%   8%
β=0.8    ¥145    ¥135 ¥130  ¥125 ¥115
β=1.0    ¥135    ¥120 ¥115  ¥110 ¥100  ← 基准格
β=1.2    ¥125    ¥110 ¥105  ¥95  ¥85
β=1.4    ¥115    ¥100 ¥95   ¥85  ¥75
β=1.6    ¥105    ¥90  ¥85   ¥75  ¥65
```

**中心格规则：** 中心格 = 基准假设（Base case WACC + 终端增长率），输出值必须等于Step 9的每股内在价值（自洽性检验）。
