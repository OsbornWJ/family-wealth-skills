# 家庭压力测试（加仓/提高权益前）

不要求精确蒙特卡洛；要求**可口述、可计算**的三问。任一项答案是「会动用家庭固定资本 / 应急金穿仓」→ IPS 红灯或强制缩量。

## 1. 权益再跌 20%

```
权益市值 × 0.8 → 新占比 = 新权益 / (总金融净资产 − 权益跌幅)
家庭固定资本是否需要填坑？ 是 → 红灯
```

## 2. 失业或收入中断 6 个月

```
应急金覆盖月数 = (现金+货基+可秒赎短债) / 月支出
< 目标月数（默认6）→ 先补安全垫，不加风险仓
```

## 3. 股债双杀（利率地板位）

- 长纯债/长久期 ETF：按久期×利率上行 50–100bp 估算回撤
- 家庭固定资本若放在长久期 → 违规，应迁到储蓄国债/短债

## 输出一句

`压力测试: 跌20%… / 失业6月… / 债回撤… → 通过|不通过`
