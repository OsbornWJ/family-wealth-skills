# 虚构演示对话（非真实账户）

下列数字与持仓均为 **示例**，请勿当作投资建议。

更完整的「脚本实跑 + 能不能买」见：  
→ [scenario-monitor-2026-09-10.zh.md](./scenario-monitor-2026-09-10.zh.md)（2026-09-10 对 `portfolio.example.json` 实跑）

---

**用户：** 红利 ETF 清仓了大约 5 万现金，想做收息，现在能买银行吗？

**Agent（应加载 `family-wealth-ips`）：**

```
能不能买: 先别买（还缺信息）
这是哪笔钱: 还没确认 —— 是自己炒股的钱，还是家里保本的钱？
这笔钱打算: 想收息，年限还没说清
应急金: 要看家底表后再算
股票类仓位: 若进收息层，要看会不会超约定比例
接下来: 先确认「哪笔钱」，再谈买什么
```

请补充：这 5 万是自己炒股用的现金，还是家里保本池？

---

**用户：** 是自己炒股的钱，应急金大概还有 8 个月支出，股票类大概 22%。

**Agent：**

```
能不能买: 可以
这是哪笔钱: 自己炒股的钱
应急金: 大约 8 个月（≥6）✓
股票类仓位: 现在约 22%，上限约 30%；这次进收息层，一般不会抬高股票风险仓
接下来: 可以谈收息买什么 → a-share-dividend-allocation
```

收息怎么选（示例口径）：一手贵不贵、晃不晃、股息高不高、分红稳不稳。  
优先：红利低波类 ETF + 几只银行分散，别单押一只。  
挂什么价：先拉实时行情，再列表。

---

**用户：** 顺便跑一下早盘，再看看今天要不要加芯片。

**Agent（`a-share-daily-monitor`）：**  
运行 `scripts/morning_check.py`（无 `portfolio.local.json` 时读 example），把报告贴进对话。  
下面是 **2026-09-10 实跑摘要**（完整三份报告见 [scenario-monitor-2026-09-10.zh.md](./scenario-monitor-2026-09-10.zh.md)）：

```
上证 3934.4 (-0.43%) | 科创50 -0.69% | 两市约 1.65 万亿（偏冷）
示例-芯片ETF 市价约 1.036（-0.67%），距配置峰值约 -4%
早盘触发: 0 条 | 尾盘: 仅军工「过成本」信息提示
```

```
能不能买: 先少买点（或不加）
依据: 震荡缩量日 + 芯片破 20MA；未触发硬止盈，但也没有进攻信号
若坚持试仓: 原计划的 1/3～1/2，并写清止损
```

---

**反例（不应发生）：**

用户说「这是配偶的保本钱」→ Agent 仍按炒股的钱推荐高波动 ETF，且没有「能不能买」结论。  
正确：结论写 **先别买**，或改走储蓄国债/短债（`a-share-bond-allocation`）。
