# 大跌定投累进阈值策略

## 问题起源

2026-07 单边下跌市,科创50从2233跌至1737(-22%),原固定-5%触发阈值在下跌趋势中一周触发4次,子弹第1周就快打光。

用户原话:「跌5%就加,那不是傻子吗」——在单边跌20%+的市场里,-5%只是刚出门。

## 累进阈值法

按科创50从当月最高点的累计跌幅,动态调整DCA触发阈值:

| 科创50累计跌幅 | 市场阶段 | 单日DCA阈值 | 触发频率预期 |
|:-------------:|:--------:|:----------:|:-----------:|
| <10% | 正常回调 | -5% | 偶尔触发 |
| 10%~15% | 深度回调 | -7% | 月中~触发1次 |
| >15% | 技术熊市 | -10% | 月末~触发1次 |

## 累计回撤触发阈值不变

累进只影响**单日触发**阈值。累计触发(5日最高收盘回撤)仍按原品种参数执行:

| 标的 | 累计阈值(不变) |
|:---|:------------:|
| AI ETF | -5% |
| 芯片ETF | -6% |
| 军工ETF | -5% |
| 创新药 | -6% |

## 回测验证

以2026年7月为例(科创50从2233→1737,-22%):

| 日期 | 科创50阶段 | 原-5%规则 | 累进规则 | 
|:---|:---------:|:---------:|:--------:|
| 7/14 -5.04% | 跌幅<10% | 触发✅ | 触发✅ |
| 7/16 -5.44% | 跌幅>10%(深度回调) | 触发❌(仍触发) | **不触发(需-7%)** |
| 7/17 -5.98% | 跌幅>15%(技术熊) | 触发❌ | **不触发(需-10%)** |
| 7/20 AI -7.92% | 跌幅>15% | 触发 | **触发✅(达-10%?→检查)** |

旧规则本月触发约4-5次,累进规则触发约2次,子弹多扛2周。

## 执行流程

每交易日检查DCA触发前,先查科创50当月最高收盘:

```python
# 伪代码
monthly_high = get_monthly_high('科创50')  # 当月最高收盘
current_kc = get_current('科创50')
drawdown = (current_kc / monthly_high - 1) * 100

if drawdown > -10:       # 正常回调区
    threshold_map = {'AI': -5, 'chip': -5, 'military': -4, 'pharma': -5}
elif drawdown > -15:     # 深度回调区
    threshold_map = {'AI': -7, 'chip': -7, 'military': -5, 'pharma': -7}
else:                    # 技术熊市区
    threshold_map = {'AI': -10, 'chip': -10, 'military': -7, 'pharma': -10}
```

## 月份重置

每月1日从当月最高收盘重新开始计算科创50累计跌幅,阈值恢复正常(-5%)。
