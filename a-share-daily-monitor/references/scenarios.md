# 专项场景库（按需加载）

## ⚡ 场景L：大跌定投 (Dip DCA) — 补充条件单的盲区

**起源：** 2026-07-10用户发现条件单设太低，芯片(最低1.348 vs T1 1.25)和军工(最低1.194 vs 1.20)全部错过。引入大跌定投机制覆盖"中等跌幅"区间。

**规则：**

| 标的 | 阈值 | 买入量 | 频率限制 | 条件 |
|:---|:---:|:-----:|:-------:|:----|
| AI ETF (515980) | 单日跌>**-5%** | 2,000股 | 每月≤2次 | 基于昨收的日内跌幅 |
| 芯片ETF (512760) | 单日跌>**-5%** | 2,000股 | 每月≤2次 | 同上 |
| 创新药 (589720) | 单日跌>**-5%** | 2,000股 | 每月≤2次 | 同上 |
| 军工ETF (512660) | 单日跌>**-4%** | 2,000股 | 每月≤2次 | 弹性小，阈值放低 |
| 建行 (601939) | ❌ 不参与 | — | — | 等除息补仓 |
| 红利 (562060) | ❌ 不参与 | — | — | 等换仓时机 |

**执行逻辑（每个交易日盘中/尾盘检查）：**
1. 拉新浪实时，计算每个标的日内涨跌幅 = (当前价/昨收 - 1) × 100
2. 如果跌幅 < 阈值（如芯片-5.48% < -5%）→ 大跌定投触发
3. 检查该标的本月已触发次数：<2次可执行，≥2次跳过
4. 通知用户：`[标的] -X.XX% 跌破阈-Y%，大跌定投触发，建议买入2,000股，需资金约¥Z,ZZZ`
5. 用户确认后执行

**与条件单的关系：**
- 条件单 = 深调抄底（设低价等极端行情）
- 大跌定投 = 抓中等跌幅（条件单等不到的区间）
- 两者不冲突：同一天如果先触发定投再跌到条件单价，两笔都执行

**特别注意事项：**
- ⚠️ 用户可自主缩减定投量：如用户只想加1,000股而非规则的2,000股，尊重用户选择（2026-07-13实战：军工触发定投但用户挂限价1k@1.20而非2k市价）
- ⚠️ 用户可挂限价单替代市价：当用户说「我先挂了X.XX Y股」→这视为对规则参数的自主调整，记录新仓位并更新成本即可
- ⚠️ 当定投触发但用户问「今天为什么跌」时→先执行外部原因诊断（见场景M），再决定是否推迟执行
- ⚠️ 当外部原因查明确实有系统性利空（战争/政策突变/全球性危机）→建议推迟定投，等次日确认
- ⚠️ 当外部原因为正常获利回吐或技术回调→建议按规则执行
- ⚠️ 【2026-07-14教训】定投条件满足后不应因外部恐慌跳过执行。7/13韩国崩盘9%引发担忧，芯片-5.04%触发定投但建议推迟；7/14市场企稳后价格相同(1.375)，用户补执行1k@1.371。推迟并未得到更低价格，反而白扛了一天风险。A股对外部冲击抗跌性强于直觉，过度谨慎反错过买点。正确做法：定投条件是客观信号，触发即执行，不因外部噪音跳过。**「今天不买，明天更低」是熊市思维，牛市里今天不买明天可能就反弹了。**

## ⚡ 场景M：下跌外部原因诊断 — 用户质疑信号时

**起源：** 2026-07-10用户问"回调有点奇怪，有什么外盘消息吗？"——在定投触发后用户先质疑原因再决策。

**当定投/条件单触发但用户表示疑虑时，走三步诊断，先确诊再执行：**

### 第一步：排除法（用已有行情数据判断）

| 症状 | 可能性 | 诊断方法 |
|:----|:------|:--------|
| 全市场普跌（上证-2%+） | 🔴 系统性利空 | 查美股期货、恒生、A50 |
| 科技独跌，主板平（上证-1%内） | 🟡 科技获利回吐 | 对比昨涨vs今跌幅度 |
| 单一标的独跌，同板块没跌 | 🟢 个股/ETF自身问题 | 查该标的新闻、折溢价 |
| 港股/外盘同步大跌 | 🔴 外部冲击 | 需警惕，建议观望 |

### 第二步：跨市场比对

```
昨日暴涨 → 今日回调 → 最可能的解释是获利回吐
特别证据：上证只跌-X%（说明不是宏观问题）
           同板块B只跌-Y%（说明不是行业问题）
           标的A跌幅最大（因为昨天涨最多）
```

### 第三步：输出结论+执行建议

```
原因：获利回吐（正常技术性回调）
判断：✅ 非系统性风险，定投逻辑不变
建议：按规则执行 / ⏳ 建议等尾盘确认再执行 / 🔴 建议观望
```
```

**核心原则：**
- 🟢 项占多数时，直接说明「无事可做有理可据」，缓解用户FOMO
- 🟡 项不超过2个，多则分散注意力
- 不加主观判断「我建议你XX」，只列数据和触发距离，让用户自己判断

### ⚡ 场景H3：下跌成因诊断 — 级联四问框架（美伊/宏观/地缘）

当用户针对某次下跌连续追问多个关联问题时——如「是XX引起的吗」「会重演YY吗」「如何应对」「钱去了哪里」——这不是四个独立问题，而是一个**级联诊断链**：

| 问号 | 目标 | 诊断方法 |
|:----|:------|:---------|
| 第1问：原因 | 是XX事件引起的吗？ | 区分「新触发器」vs「旧背景」——如果是已经持续数月的事件（如美伊僵持），市场已消化，非本轮下跌主因。真正的触发器通常是「涨多了该回调了」+「几个次要利空叠加」 |
| 第2问：对比 | 会重演YY那一波吗？ | 对比量级（跌幅%）、持续时间、触发因素。如果当前跌幅显著小于上次、市场情绪更稳定、且上次是首次冲击而这次已是消耗战 → 结论：不会重演 |
| 第3问：行动 | 如何应对？ | 检查持仓利润垫是否足够 → 让条件单工作 → 现金等待。见各专项场景 |
| 第4问：流向 | 资金去了哪里？ | 见 `references/money-flow-rotation.md` 模式一/模式二诊断 |

**一个关键洞察：** 这四问是递进的。第1问的答案决定了第2-4问的方向。如果原因定位错误（如把获利回吐当作地缘恐慌），后续所有判断都会偏差。

**输出格式（2026-07-08实战版）：**
```
### 1️⃣ 这次下跌是XX引起的吗？
是，但/不完全是。原因分解：
- 背景（长期影响，已定价）
- 触发（短期事件）
- 放大（技术面因素）
结论：XX是背景板，不是触发器。真实原因是XX。

### 2️⃣ 会重演YY那一波吗？
不会/会但量级不同。对比表：
| 维度 | 上次(YY) | 这次 |
|:----|:--------:|:----:|
| 触因 | ... | ... |
| 科创50跌幅 | -X% | -Y% |
| 持续时间 | X周 | Y天 |
结论：性质不同，不会重演。

### 3️⃣ 如何应对？
维持现状，让条件单工作。你现有的利润垫：
- AI/芯片浮盈XX% → 跌30%不伤本金
- 建行/红利 → 防御层有用
- 现金X万 → 等子弹

### 4️⃣ 资金去了哪里？为什么没有跷跷板？
诊断过程：（见money-flow-rotation模式判断）
结论：科技内部换手，资金没出来。
```

**源起：** 2026-07-08实战。用户连问四问：「这次下跌是美伊引起的吗？」「会重演3月那一波吗？」「如何应对？」「资金去了哪里，没有和创新药形成跷跷板？」——四个问题指向同一个级联分析需求。

**⚡ 「资金是否在进入」——下跌日资金流向分析流程（2026-07-14新增）**

**起源：** 2026-07-13用户问"半导体芯片在跌，看看资金是否在进入"——想知道下跌是机构在抄底还是散户在割肉。

**当用户问「资金是否在进入」「钱在买还是在卖」「有人在接盘吗」时，走以下流程：**

### 第一步：量价对比（核心诊断工具）
比较当日成交额 vs 近期基准日的成交额：

```python
今日成交额 = 新浪实时数据.amount  # 单位：亿
暴涨日成交额 = 从morning_check或记忆获取的近期参考值

结论：
量 > 基准×1.3 + 价跌 → 放量下跌，换手充分，有资金在接
量 < 基准×0.7 + 价跌 → 缩量下跌，无人接盘，抛压未出清
量 = 基准×0.7~1.3 + 价跌 → 正常量能，跟随性下跌
```

### 第二步：关联交叉验证
- 同板块内部分化？AI跌3%但芯片跌5% → 板块内部换手
- 防御品种（建行/红利）是否上涨？→ 资金避险还是真正离场
- 该标的今日成交额在同类中排名如何？

### 第三步：输出结论
```
### 量价诊断
标的 | 今日成交额 | 参考基准日成交额 | 量比 | 判断
芯片 | X亿 | Y亿(7/9) | 0.75x | ❌ 量没放，散户割肉
AI   | X亿 | Y亿(7/9) | 2.3x  | ✅ 放量，有资金接
```
**关键原则：** 缩量下跌+大跌幅=最差情景（无人接盘的恐慌）；放量下跌+小跌幅=机会（有资金在吸筹）。

**⚡ 用户质疑市场诊断时的处理流程（2026-07-13新增）**

**起源：** 2026-07-13用户问"大盘为啥跌这么狠"，我回答"内部换手"→用户说"我觉得不是，查查外围消息"→查到韩国KOSPI暴跌9%才是真因。用户是对的。

**当用户明确表示不同意你的市场诊断时（"我觉得不是这个原因""查查外围""有什么外盘消息吗"），不要辩护，立即执行以下流程：**

1. **立即承认**：不用道歉，直接说"查"或"找到原因了"，然后展示数据
2. **切换数据源**：停止用现有行情数据做推理，立即拉外部数据
3. **三线并行查**（任一成功即可）：
   - **华尔街见闻**（最可靠）：`api-one.wallstcn.com/apiv1/content/lives?channel=global-channel&limit=10`
   - **美股外盘**：新浪 `hq.sinajs.cn/list=gb_ixic,gb_dji,gb_inx`
   - **汇率/美债**：新浪 `hq.sinajs.cn/list=fx_susdcny,b1.US10YR`
4. **输出修正后的结论**：承认之前判断有误，给出新结论

**注意：** 这不是"纠正用户"，是**用户纠正你**。用户可能通过自己的渠道看到了你没看到的消息。

**典型外部催化剂查找范围：**
- 🇰🇷 韩国KOSPI暴跌 → 直接影响A股存储/芯片（三星/SK海力士是全球半导体风向标）
- 🇺🇸 美股科技（纳指/费城半导体SOX）→ 传导A股科技情绪
- 🌍 亚太联动（日经/恒生）→ 判断是否区域性危机
- 🏦 美债/汇率突变 → 宏观流动性冲击

**2026-07-13实战案例：** 用户质疑"内部换手"诊断后，查到韩国KOSPI日内跌超9%，SK海力士-14.5%，三星电子-11%，直接导致A股芯片/科技跟跌。修正后结论正确。

**⚠️ 关键修正（2026-07-08）：不要将用户带来的新闻视为背景板**

当用户主动带来一条新闻并问「这不是重磅消息吗」时，这条新闻**就是**当前的分析焦点，不要把它降级为「背景板」「已定价」「不是主因」。

**错误案例（本会话）：** 用户说「美伊谅解备忘录终结」，我回答「这是背景板不是触发器，真正的原因是涨多了」。用户当场纠正「这个不是重磅消息吗」。正确做法：把新闻作为新的事实纳入分析框架，重新评估所有持仓的受影响程度，而非坚持原有判断。

**修正后的执行流程：**
```
用户带来新闻 → 立即纳入分析
                ↓
第1层：新闻本身的影响链（事件→油价→通胀→利率→各类资产）
第2层：对比原有判断中有多少需要修正
第3层：输出修正后的结论 + 对操作的影响
                ↓
关键差异：先承认新闻的重要性，再输出分析
           不试图「解释掉」新闻的影响
```

**典型触发词：** 用户说「这个不是重磅消息吗」「你怎么看这个」「这个消息不是会影响XX吗」——这些都是修正信号，不是反驳信号。用户在提醒你更新分析框架。

**见 `references/geopolitical-catalyst-monthly-outlook.md`** — 月度展望分析框架：给定宏观催化剂（如美伊MoU终结）后，评估不同资产类别（红利vs银行）的月度受益程度。区分「确定性利好」（如建行）和「可能性利好」（如红利）。

## ⚡ 场景P：月度/期间复盘 — 用户说「XX月复盘」「总结下这段时间」

**起源：** 2026-07-10用户要求6月复盘，输出的「做对了的/可改进的/策略升级」三段式格式获得用户正面反馈。固化为此场景的固定输出结构。

**输出结构（固定三段式，不增不减）：**

### 1️⃣ 持仓逐个点评
遍历所有持仓，每个一行核心数据 + 一句关键事件总结：
```
【芯片ETF — 🏆 最佳表现】
成本X.XX → 当前X.XX (+Y.Y%)
关键事件：
  ✅ 做对的：...
  ❌ 错过的：...
  📌 教训：...
```

### 2️⃣ 做对了的
✅ 每项一句话，不超过5项。典型项：
- 止盈锁利将成本降到极低
- 条件单/定投执行到位
- 纪律性扛住暴跌没割肉
- 长线逻辑判断准确

### 3️⃣ 可以做得更好的
⚠️ 每项一句话+改进方向，不超过3项。典型项：
- 条件单设太远错过中等跌幅 → 新增大跌定投
- 没有XX机制抓到XX机会 → 已新增XX策略
- 某仓位多余/方向不对 → 等待换仓时机

### 4️⃣ 策略升级
➡️ 本次复盘后实质性的策略变更（如有）。如「已更新:条件单保底+大跌定投」

**关键原则：**
- 复盘是认错改进，不是粉饰。用户接受被指出问题，前提是附带解决方案
- "做对了的"和"可改进的"比例大约3:1，不要全是批评
- 所有批评必须附带「已改进」或「待执行计划」，不能只指出问题没有方案

| 问题 | 表现 | 怎么改 |
|:----|:-----|:------|

## ⚡ 场景I：个股加仓深度诊断 — 四问框架

当用户针对某个持仓提出「连续跌了多少天」「破5日线没」「见底了吗」「能加吗」等组合式追问时，自动走"四问框架"：

**第1问：连续下跌天数** — 用最近交易日K线数据（AKShare `fund_etf_hist_em`）检查

```
日期 | 收盘 | 涨跌   | 形态
7/6  | 0.980 | -0.10% | 🔽
7/7  | 0.920 | -6.12% | 🔽 暴跌
7/8  | 0.903 | -1.85% | 🔽 续跌
结论：连续3个交易日下跌
```

**第2问：5日线位置** — 手动计算MA5（最近5个交易日的收盘价均值），对比现价
- 现价 >> MA5 → 远离均线，超跌
- 现价 ≈ MA5 → 均线附近，窄幅震荡
- 现价 << MA5 → 大幅跌破，弱势明显

```
MA5 = (c1+c2+c3+c4+c5)/5 = X.XXX
现价 = Y.YYY
偏离 = (Y/X - 1) × 100 = -Z.Z%
→ 大幅跌破5日线（-4.7%）
```

**第3问：是否见底** — 检查三个信号
- 今日低点是否比昨日更低？→ 是则下跌趋势延续
- 是否出现典型止跌K线（锤子线、放量十字星、缩量横盘）？→ 否则未企稳
- 成交量是否萎缩至近10日均量60%以下？→ 是则抛压衰竭

三种状态：
| 状态 | 判断 | 后续 |
|:----|:-----|:-----|
| ❌ 未见底 | 低点新低+放量+无止跌K线 | 继续等待 |
| 🟡 接近见底 | 低点走平+缩量+均线乖离大 | 等确认信号1-2天 |
| ✅ 已见底 | 缩量横盘+阳线确认+低点抬高 | 可考虑加仓 |

**第4问：加仓判断** — 综合前三问输出结论

```
信号A：是否跌到你设定的价位区间
信号B：趋势是否停止（见底确认/放量阳线站回MA5）
信号C：赔率是否足够（距支撑位空间 vs 下方风险）

建议：不急于动手 / 再观察1-2天 / 可小仓试 / 等信号确认
```

**输出模板（不加多余修饰）：**
```
## [标的] 加仓分析

连续下跌：X个交易日
5日线：MA5=X.XXX，现价Y.YYY，偏离-Z.Z%（已/未跌破）
见底信号：❌/🟡/✅（理由一句话）
加仓判断：不推荐/等0.XX以下/等放量阳线站回MA5
```

**2026-07-08实战（创新药589720）：** 连跌3天，MA5=0.948大幅跌破（-4.7%），低点逐日新低+放量下跌→未见底。结论：不建议加仓，等两个信号之一：①0.90以下缩量横盘 ②放量阳线站回0.92。

### ⚡ 场景J：大反弹日分析框架 — 对称于场景A（急跌诊断）

当科创50/芯片/AI等单日暴力反弹（>5%），用户问「操作吗」「要不要追」时使用。与场景A急跌框架对称，但结论几乎总是相反的。

**前置判断：** 暴力反弹日只有两种可能——(a) V型反弹启动，或 (b) 超跌后的情绪修复（一日游）。在前3个交易日内无法区分。

**行动铁律（3条，不可违反）：**
1. **反弹日不追高** — 任何阶梯加仓档位接近现价（<3%）时，反弹日当天不执行追买。等后续回踩确认
2. **条件单距离检查** — 检查所有条件单是否仍然「安全」：距条件单 >5% 才安心；距条件单 <3% 说明反弹可能吃掉加仓空间
3. **现金仓位不动** — 反弹日不追入现金，等回调或横盘确认

**判断链（三问）：**

**第一问：量能验证 — 今日成交额是否异常？**
- 成交额 > 近10日均量×1.5且涨幅>5% → 可能是真V转（有人抢筹）
- 成交额正常（0.8~1.2x）但涨幅大 → 抛压小，轻松拉，但买盘也不积极
- 成交额 < 近10日均量×0.7 → 无量空涨，大概率一日游，警惕次日低开

**第二问：成分合理性 — 哪些在涨哪些在跌？**
- 芯片/AI/创新药齐涨 → 系统性修复，合理
- 仅芯片暴涨+红利建行跌 → 资金从防御抽到科技，风格延续
- 普涨无分化 → 情绪驱动，无持续选股主线

**第三问：动作框架**
```
反弹日动作     | 适用条件                | 结论
---------------|------------------------|--------
不操作         | 条件单远在天边          | ✅ 默认选项
等回调         | 条件单接近（<5%）       | 🟡 不追，等回踩
卖一部分       | 浮盈巨大且量价背离      | 🔴 仅限极端情况
```

**输出格式（2026-07-09实战版）：**
```
## 大反弹日分析

### 盘面定性
科创50 +X.XX% | AI +X.X% | 芯片 +X.X% → 暴力反弹日

### 条件单距离检查
标的 | 条件单档位 | 距现价 | 安全?
:---|:---------:|:-----:|:----:
AI ETF | T2 1.10 | -X% | ✅ 远
芯片ETF | T1 1.25 | -X% | ✅ 远

### 分类结论
🟢 不操作 — X项（理由：所有条件单远在天边）
🟡 可观察 — X项（理由：XX档位接近，反弹日不追，等回调）

### 一句话策略
暴力反弹日不追高，所有条件单安全，今日无事可做。
```

**关键观念：** 用户体系的核心是「让条件单工作」——反弹日意味着条件单更远了，市场在帮你省钱。反弹日追高=违反用户「赔率优先」的核心风格。

**周五盘中突破关键价位（如军工1.30、建行股息率线等），不当天执行，等周一收盘确认。**

原因：周末两天的宏观/地缘/政策不确定性，可能导致周一跳空低开，周五的突破变成假突破。

| 场景 | 周五动作 | 周一确认后动作 |
|:----|:--------|:-------------|
| 周五盘中突破但收在关口下方 | 不动 | 不确认，不执行 |
| 周五收盘站稳关口上方 | 不动 | 周一开盘执行加仓/买入 |
| 周五突破+周末有利好 | 不动 | 周一高开5%+→放弃，等回踩 |
| 周五突破+周末有利空 | 不动（还好没买） | 重新评估 |

### ⚡ 场景K：底部抬升分析框架（Rising Bottom Assessment）

当用户问「底价是不是逐步拉高」「XX的底部在抬高吗」「低点在慢慢上移吗」——这是关于标的**低点轨迹**的独立技术分析问题，区别于场景H（缩量企稳）和场景I（加仓诊断）。核心是判断低点序列的方向。

**数据采集：** 拉最近20个交易日的日K最低价（AKShare `fund_etf_hist_em` 或新浪实时K线）

**分析框架（三步）：**

**第1步：低点序列提取与分段对比**
```
日期 | 最低价
6/09 | 1.210
6/10 | 1.208
6/11 | 1.200 ← 阶段底
...
7/08 | 1.216
7/09 | 1.194 ← 新低！
7/10 | 1.239
```
分段：前5低均 vs 中5低均 vs 近5低均
```
前5低均: 1.243  中5低均: 1.247  近5低均: 1.232
```

**第2步：趋势判定**
| 状态 | 判断标准 | 结论 |
|:----|:--------|:----|
| ✅ 底部抬升 | 近期低点逐个抬高（sorted ascending）且未破前低 | 趋势向好，等回调到支撑位 |
| 🟡 震荡筑底 | 低点高低交错，但未破前低 | 方向不明，不加不砍 |
| ❌ 底部下降 | 近期低点逐个降低（sorted descending）或破了前低 | 趋势未止，加仓延后 |
| 🔴 双底/W底 | 两次打到相近低点后反弹 | 等放量阳线突破颈线确认 |

**关键判断指标：** 是否跌破前低（如1.194破了1.200），这是最重要的信号。

**第3步：对持仓的影响**
- 底部抬升 → 等回调到支撑位加仓（按场景I加仓框架）
- 底部下降/破前低 → 加仓延后，等新的底部结构形成
- 震荡筑底 → 不动，让低点自然收敛

**输出模板：**
```

（最近15个交易日的低点表）

前5低均: X.XXX  近5低均: X.XXX
最低点: X.XXX（日期）

### 趋势判定
✅/🟡/❌ 底部（是否）抬升
理由：一句话（如「7/9低点1.194破了6/11的1.200，底部未抬高」）

### 持仓影响
你的成本X.XX，现价Y.YY，浮亏Z.Z%
加仓档X.XX / X.XX → 已过/未到
建议：等回调 / 等确认 / 等新底部结构
```

**2026-07-10实战（军工ETF 512660）：**
- 6/11低点1.200，7/9低点1.194破了前低 → ❌ 底部下降
- 但7/10快速弹回1.239，1.19-1.20区域有支撑
- 结论：底部未抬高，但W型双底雏形出现。加仓等1.20深调或1.30突破确认

### ⚡ 场景O：恐慌信号识别 — 「防御开始补跌」是早期预警

**起源：** 2026-07-20实战。用户连续多日科技大跌后问「恐慌盘来了吗」「可以加大力度抄底了吗」。需要用客观信号判断恐慌级别。

**三级恐慌信号（由轻到重）：**

| 级别 | 信号 | 操作建议 |
|:---:|:----|:--------|
| 🟢 **正常调整** | 科技跌，红利涨/平，建行涨 | 按DCA规则执行，不额外加码 |
| 🟡 **防御松动** | 红利转负（-0.5%~-1%），但建行仍涨 | 接近恐慌，按规则打DCA但**不超额** |
| 🔴 **全面恐慌** | 红利暴跌（-3%+），建行跟跌，全市场无差别杀 | 考虑超额加码（需用户确认） |

**关键观察对象（按敏感度排序）：**

| 品种 | 角色 | 正常时表现 | 恐慌时表现 |
|:----|:----|:---------|:---------|
| 红利ETF | 防御 | 涨或平 | **转负**=防御松动早期信号 |
| 建行 | 防御 | 涨 | 跟跌=恐慌确认 |
| 上证 | 大盘 | -1%内 | -3%+=恐慌 |

### 场景A：全市场急跌 — 恐慌还是回调？(三问诊断框架)

**第一问：跌幅级别**

- 科创50跌3-5% = 中等下跌 → 检查是否伴随放量

- 全市场普跌2%+且无板块逆势 = 系统性 → 警惕

**第二问：成因诊断**\n- 查看是否有突发利空（美债突变、政策变化、地缘冲突）\n- 没有突发利空 = 获利回吐（正常）\n- 早盘冲高→午后跳水 = 获利盘出逃（5/21、5/27模式）\n- 开盘直接低开低走不放量 = 情绪宣泄（不恐慌）\n- **🔑 跨市场对比诊断**：如果是单一板块（如芯片/AI/医药）暴跌，查美股同板块龙头（美光MU/费城SOX/英伟达NVDA）当日表现。美股同板块涨→A股是情绪/资金驱动，非基本面问题，不要恐慌割肉。美股同板块同步跌→全球性利空，需警惕
- **🔑 跨市场对比诊断**：如果是单一板块（如芯片/AI/医药）暴跌，查美股同板块龙头（美光MU/费城SOX/英伟达NVDA）当日表现。美股同板块涨→A股是情绪/资金驱动，非基本面问题，不要恐慌割肉。美股同板块同步跌→全球性利空，需警惕

### 场景E：高浮盈持仓加仓买点框架

- 用户要的是买点不是卖点，框架重点在「买在哪里」而非「卖不卖」
- ⚠️ **必须从memory读取最新成本**，用户可能已部分止盈导致成本变更。不要用旧数据。

**高浮盈持仓的特殊处理（100%+浮盈）：**
- 旧仓浮盈100%+ = 全是利润，跌到0.5x都不伤本金
- 但新加仓的每一分钱都是真金白银投入，没有安全垫
- **新仓的止损线必须按新仓成本独立设置**，不与旧仓混算
- 加仓前必须输出加权成本预估，让用户看到拉高后的成本位置：

  旧仓: 0.5138 x 9200股 = 投入4,727元
  新仓(A档): 1.08 x 3066股 = 投入3,311元

  加权成本从0.5138拉高到0.6553——但仍然在原价以下，浮动利润仍大
  ```
- 新仓的买点评估独立于旧仓浮盈——不要因为"旧仓浮盈厚"就放宽新仓的入场标准

### 场景F：板块主线验证 — "隔日续强"检验法

当用户询问某个板块能否成为下阶段主线（如"机器人能不能当6月主线"），且该板块在恐慌日逆势走强时，用"隔日续强"检验区分真主线 vs 一日游避险：

**检验方法：**
1. **恐慌日**：查该板块当日涨跌幅是否 > 大盘且逆势红盘
2. **反弹日**（次日）：查该板块在反弹日的表现
3. **判断标准：**
   - 🟢 真主线：恐慌日抗跌 + 反弹日领涨（如5月芯片：跌时-3% vs 科创50-5%，涨时+5%）
   - 🟡 一日游避险：恐慌日逆势红盘 + 反弹日走平/跑输（如6月机器人：恐慌日+0.43%，反弹日-0.17%）
   - 🔴 跟风：恐慌日和反弹日与大盘同步，无独立走势

**2026-06-08实战案例：** 机器人在科创50-4.35%的恐慌日逆势+0.43%，但次日反弹日（科创50+1.83%）机器人仅-0.17%。结论：避险一日游，非新主线。AI/芯片才是资金真正的主线。

### 场景H：持仓标的缩量企稳判断 — 通用技术诊断

当用户问「XX缩量企稳了吗」「XX现在有趋势吗」时，用以下四步框架诊断。不靠感觉，靠数据。

**诊断流程（四步）：**

**第1步：量能分析（缩量了吗？）**
```python
# 对比近3日均量 vs 近10日均量
avg_vol_10 = sum(volumes[-10:])/10
avg_vol_3 = sum(volumes[-3:])/3
ratio = avg_vol_3 / avg_vol_10
```
| ratio | 判断 |
|:----:|:----|
| < 0.6 | ✅ 显著缩量，抛压衰竭 |
| 0.6~0.8 | 🟡 温和缩量，接近企稳 |
| 0.8~0.95 | ❌ 量能仍在，未企稳 |
| > 0.95 | ❌ 放量或持平，卖压未消 |

**特别注意：** 如果昨日是放量下跌（量能 > 近10日均量×1.3），则"未缩量"明确。

**第2步：均线排列（趋势方向？）**
```python
ma5 = sum(closes[-5:])/5
ma10 = sum(closes[-10:])/10
ma20 = sum(closes[-20:])/20
```
| 均线关系 | 趋势判断 |
|:--------|:--------|
| MA5 > MA10 > MA20 | 📈 多头排列，上升趋势 |
| MA5 < MA10 < MA20 | 📉 空头排列，下降趋势 |
| MA5 > MA10 但 MA10 < MA20 | 🔄 均线粘合，震荡 |
| 交叉混乱 | ➡️ 无明确趋势 |

**第3步：MA偏离（离支撑/压力多远？）**
```
偏离MA5%  = (现价/MA5 - 1) × 100
偏离MA10% = (现价/MA10 - 1) × 100
偏离MA20% = (现价/MA20 - 1) × 100
```
- 偏离 < -3% 且空头排列 = 加速下跌中，未企稳
- 偏离在 -1%~+1% 且缩量 = 企稳信号
- 偏离 > +3% 且放量 = 超买

**第4步：60日区间分位（在什么位置？）**
```
分位% = (现价 - 60日最低) / (60日最高 - 60日最低) × 100
```
- < 10%：接近60日底部，有支撑
- 10~30%：低位区间
- 30~70%：中位正常
- > 70%：高位

**完整诊断模板输出：**
```
## [标的] 缩量企稳诊断

### 量能
近10日均量: X.XX亿 | 近3日均量: X.XX亿 | 比值: X.XX
→ ✅/🟡/❌ 缩量判断

### 均线
MA5: X.XXX (偏离+X.XX%) | MA10: X.XXX (偏离+X.XX%) | MA20: X.XXX (偏离+X.XX%)
→ 📈/📉/🔄 趋势判断

### 位置
60日区间: X.XXX~X.XXX | 当前分位: X.X%
距前低: X.X% | 距前高: X.X%

### 结论
❌ 未企稳 — 原因（量没缩/均线空头/偏离过大）
✅ 企稳 — 条件（缩量+均线走平+区间底部）
```

**2026-06-08实战案例（创新药ETF 589720）：**
- 量能：近3日均量2.38亿 vs 近10日均量2.52亿，比值0.95 → ❌ 未缩量，昨日还放量
- 均线：MA5 < MA10 < MA20 → 📉 空头排列
- 偏离：MA5 -4.6%, MA10 -8.9%, MA20 -13.5% → 全部大幅负偏离
- 60日分位：3.5% → 接近底部但趋势未止
- 结论：❌ 未缩量未企稳，还在下降通道

**判断框架：**
- 假跌破(不操作)：偏离MA120 <2%、连续跌破≤3天、股息率>3.5% → 不动，等收复

- 绝对底线：近120日低点(约0.60)不可跌破。跌破0.60 → 必须重新评估防御仓位的角色分配
