# 家庭财富 IPS（总闸门）

本 skill 是**家庭资产规划的最高优先级**。任何买卖/配置建议在出口前必须过闸。过不了闸 → 只给「为何不能动」+ 需要用户确认的缺口，**禁止直接推荐标的或授权执行**。

下游 skill（监控、收息、债券、个股）负责执行细节；本 skill 负责**该不该做、用哪笔钱、风险预算还剩多少**。

## When to Use

- 用户提：买/卖/加仓/减仓/清仓/换仓/定投/「钱放哪」
- 涉及：家庭固定资本（配偶共有本金）、家庭固定资本、应急金、教育/养老/买房目标
- 用户问：总资产、能不能加风险、仓位是不是太高
- 会话开始做重大决策前（金额 > 家庭流动资产 5% 或动用配偶本金）

**Don't use alone for:** 纯行情解读且明确不涉及操作 → 可直接 `a-share-daily-monitor`；但仍不得给出下单指令除非过闸。

## 强制闸门（每次建议前）

按序检查；任一项红灯则停止下单建议：

| # | 检查项 | 绿灯条件 | 红灯动作 |
|:---:|:---|:---|:---|
| 1 | **钱池** | 已标明：交易弹药 / 家庭固定资本 / 蓄水池 / 家人名义账户 | 先问钱池，禁止按交易弹药默认 |
| 2 | **目标与期限** | 该笔钱用途 + 可用年限已知（或用户明确「可永久风险仓」） | 先澄清目标，不给产品 |
| 3 | **应急金** | 流动现金+短债 ≥ 约定月数生活费（默认 **6 个月**，见 `assets/ips.local.md`） | 先补应急，不增加风险仓 |
| 4 | **风险预算** | 建议后「进攻/权益类」占比 ≤ IPS 上限；单标的 ≤ 单票上限 | 削减数量或拒绝加仓 |
| 5 | **配偶/家人本金** | 若动用家人钱：已提示关系风险，且方案偏保本 | 默认拒绝加风险，除非用户书面确认 |
| 6 | **保障层粗检** | 已知有无大额未覆盖负债/健康缺口（不知则标「未核」） | 大额风险仓前先提示核对保险 |
| 7 | **再平衡** | 若已超偏离带，优先再平衡而非新开主题 | 先减超配，再谈新买点 |

完成标准：输出里出现一行 **`IPS闸门: 绿/黄/红`** + 钱池名称 + 风险预算占用一句话。

## 钱池定义（与债/收息 skill 对齐）

| 钱池 | 目标函数 | 回撤容忍 | 允许工具 |
|:---|:---|:---:|:---|
| 交易弹药 | 效率出手 | 可接受组合回撤 | 现金/货基/短债；权益按 playbook |
| **家庭固定资本** | **保本 > 锁息 > 增益** | **≈0** | 储蓄国债、短债、存款；**默认禁止**博弈型个股/高波 ETF |
| 蓄水池 | 现金停靠 | <1% | 已持短债/债基，维持 |
| 家人名义账户 | 关系优先 | 视家人 | 建议权；场外定投优先于一把梭 |

判错钱池 = 整单建议作废。

## IPS 核心参数（权威在 assets）

实时数值与目标写在 [`assets/ips.local.md`](assets/ips.local.md)。skill 正文只给默认骨架；**冲突时以 assets 文件为准**，并提示用户更新。

默认骨架（可被 local 覆盖）：

| 参数 | 默认 | 含义 |
|:---|:---:|:---|
| 应急金月数 | 6 | 月支出 × N 的流动安全垫 |
| 权益/进攻上限 | 25–30% 家庭金融净资产 | 含 A 股 ETF/个股/偏股基金 |
| 收息层目标 | ~25% | 银行+红利低波等 |
| 固收+现金 | ≥40% | 含家庭固定资本、短债、存款 |
| 单标的上限 | 15% 金融净资产 | ETF/个股均适用 |
| 再平衡触发 | 偏离目标带 ±5pt | 先调结构再加仓 |
| 家庭固定资本 | 禁投清单见 local | 默认禁：高波题材、杠杆、陌生个股 |

## 建议输出模板（规划师口吻）

```
IPS闸门: 绿|黄|红
钱池: …
目标/期限: …
应急金: X个月（缺口…）
风险预算: 进攻现Y%/上限Z% → 本次后约W%
动作: 允许 / 缩量 / 拒绝
一句话理由: …
（仅绿灯或黄灯缩量后）执行细节 → 交给对应 skill
```

黄灯 = 可给方案但必须缩量或加条件；红灯 = 无下单指令。

## 压力测试（重大加仓前）

见 [`references/stress-checks.md`](references/stress-checks.md)。至少口述一项：

- 权益再跌 20%：家庭固定资本是否被动用？
- 失业 6 个月：应急金是否够？
- 股债双杀：固收回撤是否可接受（长债地板位尤甚）？

## 与其它 skill 的关系

| Skill | 角色 |
|:---|:---|
| **本 skill** | 总闸门 / IPS |
| `personal-financial-tracker` | 家庭资产负债表与净值 |
| `a-share-bond-allocation` | 固定资本与债工具 |
| `a-share-dividend-allocation` | 收息层产品 |
| `a-share-daily-monitor` | 交易弹药层执行与监控 |
| `a-share-strategy-playbook` | 交易规则（仍须过闸） |

路由：配置/家庭钱 → 本 skill → tracker 取数 → 再分派 bond/dividend/monitor。

## 陷阱

1. 用盘面机会覆盖 IPS（「今天跌狠了所以能买家人的钱」）——禁止。
2. 「止盈」语义 ≠ 清仓；算占比用真实持仓。
3. 总资产勿重复计算：A 股可用资金 vs tracker 现金。
4. 未读 `assets/ips.local.md` 就报目标配比——先读文件。
5. 授权执行 **不能** 绕过钱池与家庭固定资本禁投。
