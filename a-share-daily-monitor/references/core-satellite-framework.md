# 核心-卫星策略框架 (Core-Satellite)

## 适用场景
当用户以ETF为核心底仓，想在相同赛道内加少量个股做超额增强时的分析框架。

## 前置条件检查
1. 用户已有ETF底仓且有一定浮盈（愿意承担个股风险）
2. 用户不打算替换ETF，而是"ETF兜底+个股博超额"
3. 确认用户对个股的容错率预期（ETF可以扛-15%，个股需更严格）

## 核心原则

### 1. 避免重复持仓
- 查到用户持有ETF跟踪的指数成分股权重
- 优先推荐ETF中权重不高但有独立α逻辑的个股
- ETF排名前5的重仓股如果再买个股=重复持仓，增强效果被稀释

### 2. 标的筛选三步
```
① 同一赛道（AI/芯片/医药等）→ 用户看得懂
② ETF权重中等（不排前3但也在前10）→ 避免重复
③ 独立α逻辑（和ETF主要驱动力不同）→ 真正超额
```

### 3. 门槛评估
- A股1手=100股
- 必须按实时价格计算实际门槛（2026-06-02教训：中际旭创1192元/股→1手11.9万）
- 卫星仓位金额建议控制在总资金20%以内
- 卫星仓位如果只有5000-8000元预算，只能买中科曙光(86元)、长电科技(75元)这类

### 4. 个股止损纪律
- 个股容错率远低于ETF，建议-15%无条件砍
- 不设"再看看"的弹性空间——个股没有ETF的分散保护

## 响应模板

当用户问"我的ETF有什么个股可以增强"时：

```
## [赛道] 个股增强分析

你的底仓：
  XXX ETF — 成本X.XX × X股 = 市值X元  浮盈+X%

### 指数权重TOP10
(列出前10大权重股，标注你已通过ETF持有哪些)

### 推荐标的（优先序）
🥇 [名称+代码] — 逻辑 + 门槛 + 不重复持仓
🥈 [名称+代码] — ...

### 动手前检查清单
□ 实时价格确认（不要用估算价）
□ 买点是否在MA60以下（不追高）
□ -15%止损已设置
□ 卫星仓位不超过总资金20%
```

## 坑
1. **股票价格必须以实时数据为准** — 不要用记忆里的价格或几周前的数据。2026-06-02教训：中际旭创实际1192元/股不是80元/股。每次输出前拉新浪实时行情确认。
2. **沪深市代码前缀不同** — 上交所6开头用`sh`，深交所0/3开头用`sz`，科创板688开头用`sh`
3. **一手=100股不是1股** — 计算门槛时必须×100
4. **避免推荐ETF已经重仓的个股** — 用户通过ETF已经间接持有，再买个股等于重复押注，没有分散效果
