# 错失买点后的追高决策框架

## 场景

用户明确了加仓计划（如创新药ETF在0.765-0.770加仓），但犹豫中价格涨上去买不到了（涨到0.800+）。用户问「怎么办，追不追？」

## 核心矛盾

```
想买 → 等 → 涨了 → 后悔没买 → 想追 → 又怕追高被套
```

这不是基本面问题，是**行为金融学问题**。不解决「后悔感」用户会反复犯同样的错。

## 三问决策树

### 第一问：涨幅多大？

| 涨幅 | 判断 | 动作 |
|:----:|:----|:------|
| <3% | 🟢 浮尘波动，不算追高 | 可以买，和计划差不大 |
| 3~8% | 🟡 开始疼了，但还能接受 | 权衡后可以买一半 |
| 8~15% | 🔴 明显追高 | 等回调，不追 |
| >15% | 💀 主升浪已过 | 彻底放弃，等下一个周期 |

### 第二问：趋势结构变了吗？

```
上次看的底部结构（6次触底不破）还成立吗？
前低0.723被跌破了吗？  →  破了=结构失效
MA10/M20方向？          →  下行=反弹不是反转
```

**关键：如果底部结构还在（前低没破、均线开始走平），现在的价格只是「验证中的买点」不是「错过的买点」。**

### 第三问：错过后的成本差异有多大？

```python
# 算错过成本
计划价 = 0.776  # 原计划
现价   = 0.800  # 现价
差 = 现价 / 计划价 - 1  # = +3.1%

原计划加5000股：
  错过成本 = 5000 × 0.800 - 5000 × 0.776 = ¥120
  均价影响 = (9200×0.928 + 5000×0.800) / 14200 = 0.8829
         vs (9200×0.928 + 5000×0.776) / 14200 = 0.8745
  浮亏差异: -11.3% vs -11.9% → 只差0.6个百分点
```

**大多数时候，"错过"的成本远小于"追高被套"的成本。** 但用户的心理感受是反过来的——「没买到」的懊恼 >「买贵了」的心疼。

## 三种标准回应

### 方案A：追（涨幅<3%+底部结构未破坏）

```
涨幅不大，底部结构还在，想买可以买。
但别按原计划的量——减半。
原计划加5,000 → 加2,500，既有参与感又不过度暴露。
```

### 方案B：等回调（涨幅3-8%）

```
涨了3-8%，追的话万一回调到原价位你会更难受。
挂条件单在原价位附近（如0.78），到了自动成交。
没到就不买——说明你确实错过了这班车。
```

### 方案C：放弃（涨幅>8%或结构已破）

```
错过了就是错过了。
下一班车在哪？（换个标的重新开始）
```

## 案例：创新药ETF 2026-06-22/23

```
原计划: 0.776 加5,000股（6/22收盘价）
结果: 没加
第二天: 开盘0.800 涨到0.816
涨幅: +5.2% → 进入方案B范围
```

**正确回应（方案B）：**
```
涨了5%，追的话心里会不舒服。
挂个条件单0.78-0.79区间，到了自动买。
没到就说明这班车确实赶不上了，等下一轮。
```

## 预防机制

### 第一次提到买点计划时，约定「执行纪律」

```
计划: 加5000股@0.776
执行窗口: 3天（从今天到本周五收盘）
条件: 站上MA10 → 加；否则 → 等
```

有了明确的「过期时间」和「取消条件」，用户就不会在价格跑掉后反复纠结。因为条件已经定了——没触发就是不该买，不是买慢了。
