# 多标的操作优先级决策规则

当用户同时面对多个持仓的操作决策时（例如：建行触发减持、红利跌破MA120、科技大跌想加仓），用这个框架排优先级。

## 核心原则：锁利 > 止损 > 进攻 > 防御调整

操作优先级从高到低：
1. **锁利（有盈利的卖出）** — 优先于所有其他操作。利润不是真实的，直到它被锁定。
2. **硬止损（亏损到达预设线）** — 保护性止损不可延迟。0.84减半/0.82全清必须执行。
3. **进攻加仓（科技急跌时的捡筹码）** — 现金的意义在于等机会。有预案才动手。
4. **防御调整（红利/建行的仓位优化）** — 最不急的操作。防御仓位的调整可以等行情明晰再做。

## 建行减持三档方案

| 方案 | 动作 | 适用场景 | 推荐等级 |
|-----|------|---------|---------|
| 🔴 A. 不动 | 全部持有 | 银行板块在上涨趋势中，用户有更高收益预期，且**涨幅<10%**（仅赚了不到10%可再拿拿） | ⭐⭐⭐ 注意：触发条件已满足，不动是主动选择而非默认 |
| 🟢 B. 卖一半 | 卖一半，留一半 | **默认推荐方案**。无论涨幅多少，股息率<4%即考虑执行。锁定利润回收子弹，留一半继续吃涨幅+分红 | ⭐⭐⭐⭐⭐ |
| 🟡 C. 全清 | 全部清仓 | 银行板块见顶信号明显，或需要大量现金去抄科技底 | 条件性推荐 |

### 机构目标价推导方法

当无法直接获取目标价时（AKShare的`stock_research_report_em()`不包含目标价字段，东财API停用），用此方法估算：

```python
import akshare as ak

# 1. 获取机构EPS共识
df = ak.stock_profit_forecast_ths(symbol='601939')
# 列: ['年度', '预测机构数', '最小值', '均值', '最大值', '行业平均数']
eps_2026 = 1.32  # 均值

# 2. 获取当前PE估值
df_val = ak.stock_value_em(symbol='601939')
latest_val = df_val.tail(1)
pe_current = latest_val['PE(TTM)'].values[0]  # 如7.9

# 3. 三情景目标价推算
target_conservative = round(eps_2026 * 7.0, 2)   # PE保守
target_neutral = round(eps_2026 * 7.5, 2)         # PE中性
target_optimistic = round(eps_2026 * 8.0, 2)      # PE乐观（历史高位）
```

银行PE通常7~8倍。PE>8倍进入历史高风险区（参考2018年1月和2026年5月）。PE更低的时说明被低估。

### 分红决策数学（持有到除息 vs 提前卖）

当用户在高股息标的上有浮盈+，问「要不要等分红」时，用这个计算框架：

**标准计算模板：**
```
现价 = P, 每股分红 = D, 持仓成本 = C
税率(持1月~1年) = 10%, 税后红利 = D × 0.9
持有到除息日总价值 = (P - D) + D×0.9 = P - 0.1D
现在卖价值 = P
差额 = P - (P - 0.1D) = 0.1D
差额比例 = 0.1D / P × 100%
```

**核心结论：** 分红税（10%）是持有到除息的真实成本。差额 = 0.1 × 每股分红，通常只有0.2%~0.5%——**数学上几乎无差别**。例外：
- 持有>1年免征红利税 → 持有到除息反而多拿D的沉淀利息（极小）
- 持有<1个月征收20%税 → 差额翻倍，但仍<1%
- 若股价除息后快速填权 → 持有方案胜出

**话术模板：** 「从分红数学看，现在卖比持到除息多拿0.04元/股（-0.4%），几乎可忽略。分红不是持有理由也不是卖出理由——它是中性的。真正该问的是：你还想不想持有这个标的做防御？现金拿回来有没有更好的去处？」

**场景B的卖出节点选择**

三个执行窗口（按推荐顺序）：

**方案B-1：尾盘卖出（推荐⭐⭐⭐⭐⭐）**
- 条件：今天日内建行大幅冲高后回落（如冲+1%→翻绿），尾盘挂现价卖
- 逻辑：冲高回落说明抛压重，今天不出明天可能更低
- 风险：明天反弹则少赚一点

**方案B-2：等反弹到阻力位卖（推荐⭐⭐⭐⭐）**
- 条件：次日或后续交易日，建行反弹回到今日日内高点附近（如10.40~10.45）时卖
- 逻辑：卖在反弹高点，多赚1-2%
- 风险：可能等不来反弹，反而越跌越低

**方案B-3：分两批卖（推荐⭐⭐⭐）**
- 条件：今天先卖1/4，等反弹再卖1/4
- 逻辑：折中方案，既锁利又保留弹性
- 风险：操作复杂，容易犹豫

### 用户对话实录：尾盘操作时用户问机构目标价

2026-05-27盘中14:52，建行10.23，用户犹豫要不要卖，问「90天机构目标均价是多少」。当时的真实数据：

- 13家机构预测2026年EPS均值1.32元
- 当前PE(TTM)=7.9倍（处于2018年大顶水平）
- 中性PE 7.5x×1.32EPS=9.90元（低于现价）
- 乐观PE 8.0x×1.32EPS=10.56元（高现价3.2%）
- 结论：现价10.23已经达到甚至超过机构隐含目标价，上行空间仅0~3%

回答模板：「当前XX的PE是X倍，已经处于历史高位区间。机构预测XX年EPS X.XX元，按X倍PE算只值X.XX元，现价已经透支。上行空间有限，建议锁利。」

## 当一个标的锁利、另一个标的在亏、第三个在跌时怎么选

**建行卖一半 → 回收现金 → 红利亏损-1.3%小亏不动 → 科技大跌等预案执行**

具体决策链：
1. **建行有+12.8%利润** → **卖一半**（锁利最优先）
2. **红利亏-1.3%** → **不动**。原因是：
   - 亏损幅度小（1.3% vs 建行利润12.8%），止损的必要性远低于锁利的必要性
   - 红利是防御仓，亏损在正常波动范围内
   - 如果为了去加仓科技而砍红利，是"卖掉防御去买进攻"，仓位的风险暴露会急剧增大
3. **科技如果在跌** → **等恐慌急跌预案**（见 references/panic-buy-guide.md，如果有的话，否则参考专项场景A）

## 关键心理法则

- **锁利和止损是两回事，不要混为一谈。** 赚12.8%的标的减仓和亏1.3%的标的减仓不是同一个决策。
- **砍红利去补科技 = 把防御变进攻。** 除非你明确想提高风险敞口，否则不要这样操作。
- **有利润的标的优先操作** — 永远先处理盈利的，再处理亏损的。
- **现金不是闲置的，是在等机会。** 卖建行回收5万，这笔弹药有明确用途才值得卖。没有预案的话，留着建行吃股息也行。
