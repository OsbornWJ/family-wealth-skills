# 持仓综合评分框架

当用户问「分析下我的持仓」「我的持仓怎么样」「给持仓打个分」「结合你的策略给持仓评分」时使用。

## 前置检查（必须先于评分）

1. **持仓新鲜度确认** — 检查memory中的持仓数据是否过时。对比监控脚本的COST_PRICE字典确认活跃标的。如果数据来源是几天前的会话，先问用户是否有更新。参考陷阱「持仓名单确认优先于成本确认」。
2. **成本确认** — 走三步确认法：memory读取 → 输出让用户确认 → 用户确认后输出浮盈。成本不一致时整个评分无效。
3. **风格确认** — 拉当日大盘（上证/科创50），判断当前市场风格（成长/防御/均衡），这是评分的基准背景。
4. **拉实时行情** — 用新浪 `hq.sinajs.cn` 拉持仓全部标的的实时价/涨跌/高/低。不得使用memory中的旧价格。

## 第一层：宏观三层滤网（用户亲自教授的分析基因）

任何评分前，先用三层框架判断各标的所处的宏观位置。每一层对应一个不可跳过的问题：

### 🌡️ 第一层：流动性 — 水温是冷还是暖？

| 指标 | 信号 | 对持仓的影响 |
|:----|:----|:------------|
| 美债10Y > 4.5% | 🔴 压制成长股估值 | AI/芯片/创新药受压制 |
| 美债10Y 4.0~4.5% | 🟡 中性偏高 | 科技震荡不崩不涨 |
| 美债10Y < 4.0% | 🟢 系统性重估 | 成长股主升浪窗口 |
| 美债10Y < 3.5% | 🟢🟢 最强宽松 | 全面上涨 |
| 中美利差（中债-美债） | 越大越压制A股 | 利差>250bp时A股承压 |
| 中国央行利率 | 降息偏松/加息偏紧 | 直接影响银行息差 |

**核心逻辑：美债不降，科技股不崩但也不暴涨；美债一降，AI/芯片是第一受益者。**

### 🌬️ 第二层：政策 — 风往哪吹？

在中国做投资必须看懂政策的指挥棒。读通稿：中央经济工作会议、政治局会议、政府工作报告。

| 风向 | 行业举例 | 对持仓的影响 |
|:----|:---------|:------------|
| 🟢 新质生产力/AI | AI、算力、芯片 | AI/芯片最直接受益 |
| 🟢 绿色发展/固废 | 环保、垃圾焚烧 | 瀚蓝环境顺风 |
| 🟢 国产替代 | 半导体、信创 | 芯片ETF核心逻辑 |
| 🟢 设备更新/以旧换新 | 制造业、新能源 | 间接利好 |
| 🔴 化解过剩产能 | 传统钢铁/煤炭 | 不持有则无影响 |
| 🔴 集采/控费 | 医药 | 已出清，政策逆风转顺 |

### 🏔️ 第三层：人口与技术 — 长期的坡道

两个不可逆的慢变量：

| 变量 | 方向 | 影响持仓 |
|:----|:----|:---------|
| 人口老龄化 | → 医疗健康需求持续增长 | 创新药长期逻辑成立，但兑现期可能数年 |
| AI技术革命 | → 算力需求指数级增长 | **芯片/AI是最直接的受益者** |

**AI不是「一个行业」，它是基础设施。** 就像2000年的互联网、2010年的移动互联网一样。

### 行业格局判断：数月亮还是数星星？

邱国鹭的核心思想：**宁可数月亮，不要数星星。**

| 格局 | 特征 | 例子 |
|:----|:-----|:-----|
| 🌙 **月朗星稀**（最好） | 寡头垄断、龙头有定价权 | 高端白酒、通讯运营商、四大行 |
| 🌟 **从数星到数月**（拐点） | 行业出清后集中度提升 | 固废处理（瀚蓝所处阶段） |
| ✨ **繁星满天**（最差） | 高度分散、激烈竞争 | 服装、餐饮、早期Biotech |

**认知差是超额收益的来源：** 市场还在用「数星星」阶段的估值给一个已经进入「数月亮」初期的行业定价时，就是最佳买入时机。

## 第二层：逐标评分（每项1~10分）

按三层框架逐标打分。分数是判断的工具，不是目的。每个标的输出一个评分表。

### 评分维度模板

对每个持仓标的，按以下维度评分（灵活选择适用维度，不强制全部覆盖）：

```
#### 🟢/🟡/🔴 **[标的名称]** — 评分：**X/10**

| 维度 | 评价 | 得分 |
|:----|:----|:---:|
| 🌡️ 水温 | 美债敏感度、利率环境 | X |
| 🌬️ 风向 | 政策顺风/逆风 | X |
| 🏔️ 坡道 | 人口技术长逻辑 | X |
| 💰 浮盈 | 盈亏状态、安全垫厚薄 | X |
| 📉 回撤/风险 | 距止损线距离或峰值回撤 | X |

**结论：** 一句话定性。**不需要动 / 需要关注 / 需尽快处理。**
```

### 评分参照表

| 分数 | 含义 |
|:---:|:----|
| 9~10 | 最优：长坡厚雪+厚利润+政策顺风，任何价格波动都不应动摇 |
| 7~8 | 良好：逻辑清晰但有小瑕疵（如浮盈不够厚/宏观压制），关注但不操作 |
| 5~6 | 一般：有明确短板（如鸡肋仓位/深套等待），需要决策但不用恐慌 |
| 3~4 | 问题：多个维度不理想，进入决策列表 |
| 1~2 | 危险：应优先处理 |

## 第三层：组合整体评分

| 维度 | 评分点 |
|:----|:-------|
| ⚔️ **进攻端** | AI+芯片，评分最高的两个标的的平均分 |
| 🛡️ **防御端** | 建行+红利，评分 |
| 👁️ **观察端** | 创新药+军工，深套标的评分 |
| 💰 **现金管理** | 现金占比是否充裕，弹药是否充足 |
| 📊 **仓位纪律** | 整体仓位比例是否匹配市场环境 |

### 输出格式

**组合整体评分：X/10**

```
| 维度 | 得分 | 点评 |
|:----|:---:|:----|
| ⚔️ 进攻端（AI+芯片） | X | ... |
| 🛡️ 防御端（建行+红利） | X | ... |
| 👁️ 观察端（创新药+军工） | X | ... |
| 💰 现金管理（14.3万） | X | ... |
| 📊 仓位纪律（40%） | X | ... |
```

## 第四层：优先级排序

按用户定下的 **锁利>止损>进攻加仓>防御调整** 规则输出操作优先级。

```
| 优先级 | 操作 | 标的 | 理由 |
|:-----:|:----|:----|:----|
| **1️⃣** 🟢锁利 | 卖一半XX | XXX | +X%利润+X条件触发 |
| **2️⃣** ♻️换仓 | XX换XX | XXX | 亏不多，换低估价值品种 |
| **3️⃣** 👀观察 | XX盯止损线 | XXX | 新仓X.XXX/旧仓看长期 |
| **4️⃣** ⏸️不动 | XX继续扛 | XXX | 深套金额小硬扛 |
| **5️⃣** ✅持有 | XX不动 | XXX | 最赚钱的，别动 |
```

---

## 特殊规则

- **「锁利不止损」是用户的风格特征**：盈利仓位按规则锁利，亏损的不砍等催化剂。评分不能因浮亏就建议止损——要区分观察仓深套（低分但用户接受）和进攻仓深套（低分需处理）。
- **「已止盈≠已清仓」**：用户说「已止盈/之前止盈」可能指「赚过一波但仓位还在跑」，不是「已平仓」。确认方法是查监控脚本的COST_PRICE字典。
- **大仓位低分**：如果最大仓位标的得分最低，说明组合头重脚轻，需优先处理。
- **亏损不负分**：浮亏标的的评分反映的是「风险和等待成本」而非「该不该割肉」。用户接受亏损扛的逻辑——评分只需指明位置，不越俎代庖替用户决策。
- **评分要伴随「一句话结论」**：每个标的评分后紧跟一句定性的结论——「不需要动」「需要关注」「需尽快处理」。只说分数不说怎么做的评分是半成品。
