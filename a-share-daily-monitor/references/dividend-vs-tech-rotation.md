# 红利 vs 科技 资金轮动分析

2026-06-16观察记录。FOMC周典型的跷跷板效应。

## 轮动模式

当市场预期美联储偏鸽时，资金从防御板块（红利/银行）流向进攻板块（科技/AI）：

```
FOMC偏鸽预期
  ↓
风险偏好提升
  ↓
资金撤出：红利ETF（-1.46%）、银行（-1~3%）
资金流入：科创50（+3.92%）、AI（+4%）、芯片（+4.5%）
```

## 为什么红利在跌

1. **跷跷板效应（主因）** — FOMC偏鸽预期 → 降息利好成长股 → 机构调仓从红利到科技
2. **获利盘了结** — 红利ETF年初至今涨~15%，四大行涨30-50%，科技一反弹就出货
3. **国债收益率低位** — 10Y国债1.6%，红利4%股息率的相对吸引力下降。科技一天涨4% = 红利一年的收益

## 关键判断

| 观察 | 结论 |
|:----|:-----|
| 红利ETF下跌伴随科技大涨 | 正常轮动，非基本面恶化 |
| 红利ETF下跌伴随科技也跌 | 系统性风险，需警惕 |
| 红利ETF缩量阴跌 | 资金缓慢流出，非恐慌性抛售 |

FOMC落地后，资金可能回流红利。但用户已决定科技方向为主，红利作为防御底仓不动。
