# 资金流向诊断 — 为什么XX跌了？钱去哪了？

## 触发场景

用户问「为什么XX还在跌」「钱去哪了」「说好的XX涨了怎么没感觉到」，此时市场存在表象（某个指数翻红）与感受（持仓没涨）的背离。

## 诊断流程（三步）

### 第1步：比较「早盘冲高」vs 「当前价」

很多涨幅是开盘10分钟冲出来的，之后一路回落。用户看到的是9:55的 snap，感受的是10:30的真实。

```python
# 从新浪数据解析
early_high = current # 早盘冲高值
current_price # 当前实际价
gap_pct = (current_price - open_price) / open_price * 100
# gap < -1% = 早盘涨幅已回吐
```

**关键判断：** 如果所有持仓标的的早盘冲高都已回吐，说明市场没有真正的方向——不是「科技涨了」，是「科技开盘冲了一下没人跟」。

### 第2步：检查防御/大盘股是否在偷涨

当用户说「科技没涨」时，同时检查：
- 建行/银行板块：资金常从科技→防御切换
- 红利ETF/高股息：资金是否在定价「避险」
- 上证50/沪深300大票：市场是否在「杀小票买大票」

**2026-07-07 实战案例：**
- 09:55 AI +1.36%, 芯片 +1.20%, 科创50 +1.62% ← 看起来科技涨
- 10:27 AI -0.17%, 芯片 +0.57%, 建行 **+1.76%** ← 实际是建行在拉
- 结论：科技早盘冲高回落，资金其实去了建行（银行防御），用户感受正确

### 第3步：输出「钱去哪里了」的判断

```python
结论格式：
「早盘XX冲高到Y.YY后一路回落至Z.ZZ，涨幅基本吐回去了。
  资金实际流向了XX（建行+1.76%），说明市场畏高、转向防御。
  你的感受没错——持仓没涨不是幻觉，是数据。」
```

## 核心原则

1. **相信用户的感受** — 用户说「没涨」时，先去验证数据，不要用早盘分析的数据反驳
2. **不要只看涨跌幅** — 要比较「09:55早盘高位」和「当前价」两个时间点
3. **找到资金的实际去向** — 科技没涨不等于大盘没涨，建行/银行/防御板块可能才是资金真正的目的地

## 拓展：科技反弹 → 创新药被抽血（轮动对称模式）

创新药的角色是**科技暴跌时的对冲仓位**。当科技反弹时，这个逻辑反向成立：

| 市场状态 | 科技（AI/芯片） | 创新药 | 轮动方向 |
|:--------|:--------------:|:------:|:--------|
| **科技暴跌日**（如7/2 -8%） | 🔴 大跌 | 🟢 逆势红盘 | 资金逃入医药避险 |
| **科技反弹日**（如7/6 V反） | 🟢 企稳反弹 | 🔴 被卖出 | 资金从医药回补科技 |
| **震荡日**（如7/7） | 🟡 小幅波动 | 🔴 继续被抽 | 轮动延续 |

**2026-07-07 实战诊断：** 科技早盘冲高后虽回落，但科创50全天+0.31%仍红。创新药从0.980跌到0.932（-4.9%），跌幅远超其他板块。原因不是创新药基本面出问题，而是**科技企稳后，资金不再需要医药做对冲，卖出换回科技**。

**回应格式（用户问「为什么创新药又跌了」时）：**

```
创新药今天跌是因为科技在涨，对冲盘被抽血了。
7/2科技暴跌-8%时创新药+1.16%逆势红盘
7/6科技V反+1.04%，创新药-0.10%
7/7科技继续稳住，创新药-3~5%
这是轮动的正常节奏，不是基本面问题。
等科技这波反弹到位、资金又会轮回来。
```

**操作结论：** 轮动性下跌不加仓不减仓。创新药成本在下方（0.9216），还有安全垫，扛过去等轮动回来。

## 2️⃣ 模式二：内部换手（假轮动）— 科技资金实际没出来

### 触发场景

科技板块日内小幅下跌（-1%~-3%）或剧烈震荡，但**创新药同步下跌**，没有出现预期中的跷跷板效应。用户问「资金去了哪里」「为什么创新药没涨」。

### 诊断流程

**第1步：检查科技成交量 — 是否放量换手？**

如果科技ETF（AI/芯片）当日成交量显著放大（>昨日1.5倍），同时价格在低位大幅震荡（振幅>3%），说明资金在**科技内部换手**，不是系统性撤出。

**第2步：检查全市场成交额 — 是否整体萎缩？**

如果全市场成交额萎缩（<1.5万亿），说明没有增量资金。资金在存量博弈中无法同时推动科技和医药。

**第3步：交叉验证创新药的独立走势**

对比创新药当日走势 vs 科创50/科技ETF走势，判断是「跟随下跌」还是「独立下跌」：

| 创新药走势 | vs 科技走势 | 判断 |
|:----------|:-----------|:-----|
| 同步下跌，跌幅相近 | 科技也跌 | 系统性走弱，非医药独立问题 |
| 科技跌但创新药逆势涨 | ✅ 轮动（模式一） | 对冲生效 |
| 科技震荡，创新药跌更多 | 科技内部换手 | 假轮动（模式二），科技没出来 |
| 科技涨，创新药跌 | 抽血效应 | 正常回补科技 |

### 核心逻辑

**为什么科技资金没出来但创新药也没涨？**

```
模式一（真轮动）：科技恐慌 → 资金大规模撤出 → 逃向医药避险
                 → 科技暴跌(-8%)，医药逆势(+1%)

模式二（假轮动）：科技震荡 → 资金内部换手 → 没去任何地方
                   （从AI换到芯片、从高位股换到低位股）
                 → 科技平盘(-1%)，医药跟跌(-2~3%)

为什么医药在模式二也会跌？
1. 存量博弈下，医药的防御溢价是「科技恐慌」给的
2. 科技不恐慌 → 医药不需要避险 → 溢价消失
3. 医药自己在消化前期涨幅（如589720从0.753→0.981，+30%）
4. 两个板块都是利率敏感型，在利率高位→双杀
```

### 三问判断框架（用户问「为什么创新药没涨？」时）

```
Q1: 科技恐慌吗？（单日-5%+ / 放量暴跌 / 科创50-3%+）
  YES → 模式一（真轮动）→ 医药应该涨，如果没涨则说明医药自身问题
  NO  → 模式二（假轮动）→ 医药跟跌正常，等

Q2: 医药自己在涨什么？（近10日涨幅>15%？）
  YES → 医药在消化自己的涨幅，和科技无关
  NO  → 再看Q3

Q3: 全市场在增/缩量？
  缩量 → 存量博弈，科技/医药只能二选一 → 资金选科技 → 医药弱势
  放量 → 增量入场 → 科技和医药应同步走强（否则医药有独立问题）
```

### 2026-07-08 实战诊断

```
用户观察：科技震荡下跌，但创新药也没涨

Q1：科技恐慌吗？
- 科创50 +0.77%（收红）
- 芯片振幅+7.6%但收+0.28%（剧烈换手，非恐慌）
- AI 收+1.37%（反弹中）
→ 科技不恐慌 → ❌ 模式一不成立

Q2：医药在涨什么？
- 589720从0.753(6/17)涨到0.981(7/3)，+30%
- 最近4天(7/6-7/8)回到0.894
→ 正在消化自身涨幅，和科技无关

Q3：全市场成交？
- 上证成交1.19万亿（萎缩）
→ 存量博弈

结论：假轮动（模式二）。科技资金在内部换手没出来，
      医药自己在消化前期涨幅。不加仓不减仓，等。
```

### 操作结论

| 模式 | 判断依据 | 操作 |
|:----|:--------|:----|
| 真轮动（模式一） | 科技恐慌-5%+，医药逆势红 | 不追医药（涨完了），等科技加仓机会 |
| 假轮动（模式二） | 科技震荡换手，医药跟跌 | 不加仓不减仓，创新药等缩量企稳再加 |
| 抽血（科技反弹） | 科技涨，医药跌 | 创新药不加仓（还会被抽），等科技反弹到位 |
