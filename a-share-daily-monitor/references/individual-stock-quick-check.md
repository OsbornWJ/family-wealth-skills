## 评估框架（三问否决）

### ① 估值是否合理？
- 看现价和营收体量 → 155块/42亿营收 = 估值可能严重偏离基本面
- 如果PE不可得或极高 → 红牌警告
- 高位放量跌（>5% + >10亿成交额）= 主力出货信号

### ② 和你现有持仓重叠度？
- ⚠️ **分两种情况判断：**

**情况A：用户随机问个股**（不是想构建策略，只是看到了问一下）
  - 如果属于AI/芯片/科技 → 你已经通过ETF充分暴露
  - 再买个股等于三倍押注同一方向
  - 分散化原则：不买已有ETF覆盖的赛道个股
  - 结论：不建议

**情况B：用户主动提出核心-卫星策略**（找ETF底仓的个股增强标的）
  - 这是不同的场景——用户有意识用小仓位博α
  - 检查该个股在ETF指数中的权重（前5重仓=重复持仓，pass）
  - 检查个股细分环节是否和ETF主驱动力不同（ETF偏芯片设计→个股市封测=互补）
  - 用户已设止损纪律（-15%）
  - 结论：可以推荐，按核心-卫星框架（见 references/core-satellite-framework.md）

**判断依据：** 从用户的提问方式分辨。如果用户问"我的ETF有什么个股可以增强"=场景B；如果问"XX股能买吗"=场景A。

### ③ 时机对不对？
- 今天是否放量下跌？
- 是否处于历史高位？
- 是否有独立催化剂还是纯跟风炒作？

## 默认结论模板

如果三问任一不通过 → 建议不入。输出要点：
1. 标的是什么（一句话）
2. 今天为什么跌/涨
3. 三问否决原因（每条一行）
4. 替代建议（如果有的话）

## 案例

### 申菱环境（2026-05-26）
- 数据中心温控龙头，AI算力配套商
- 今日155.77 -6.89%，放量17亿从164杀到153
- 否决原因：太贵（155块）、AI已重仓（515980+512760）、高位放量跌（出货信号）
- 替代：如果想投散热方向，看数据中心ETF而非单票

### 蓝色光标（2026-05-28）
- AI营销龙头，A股最大营销传播集团
- 今日16.15 +2.41%，振幅5.9%（15.41~16.32），成交额37.3亿巨量
- 否决原因：追高（盘中+2.41%放量拉升）、题材与AI ETF高度重叠、游资博弈剧烈
- 替代：等缩量回踩15.0~15.5再建观察仓

### 中科曙光（2026-06-02）
- AI服务器/算力硬件龙头，和AI/芯片ETF同赛道不同细分环节
- 现价86.02，1手=8600元，从100.71高点回调-14.6%，缩量至均值54%
- 财务状况：营收149.6亿(+13.8%)，净利21.8亿(+13.9%)，毛利率30.6%
- 结论：卫星仓位候选（核心-卫星框架），等大盘企稳可上A档试探仓

## API回退链

当评估个股时，数据获取按此顺序：

```
① 新浪实时 hq.sinajs.cn → 当日行情（最快）
② 新浪K线 money.finance.sina.com.cn → 日K+均线（推荐）
③ AKShare stock_yjbb_em → 年度营收/利润/毛利率
④ 东方财富 push2 API → 不稳定，回退选项
```
