# 大额加仓前多想一眼

不要求精确模型；能口述就行。任一项是「会动到家里保本的钱 / 应急金不够」→ **先别买**，或必须少买。

## 1. 股市再跌 20%

```
股票市值 × 0.8 → 看新占比
会不会因此动用家里保本的钱？ 会 → 先别买
```

## 2. 失业或收入中断大约半年

```
应急金月数 = (现金+货基+能较快赎回的短债) / 月支出
不到目标（默认6个月）→ 先留够吃饭的钱，再加风险
```

## 3. 股票和债券一起差（利率很低时尤其要小心）

- 放很长久期的债：利率回升时可能亏一截
- 家里保本的钱若放在长久期债里 → 不合适，应偏向储蓄国债/短债

## 输出一句

`压力测试: 跌20%… / 失业半年… / 债回撤… → 过关|不过关`
