# A股财报业绩分析框架

## 适用场景

**使用：** 用户要求分析个股最新财报、业绩预告、季度更新
**不使用：** 首次覆盖（应走五步验尸+三法估值全流程）、宏观行业分析

---

## 核心原则

1. **时效性优先** — 财报发布后24-48小时内产出，不依赖训练数据的旧信息
2. **聚焦变化** — 重点回答：超预期/不及预期？变化原因？对估值影响？
3. **对比基准** — 同比（上年同期）+ 环比（上季度）+一致性预期（如有）
4. **数据必须可溯源** — 每个数字标注来源（AKShare报告/巨潮资讯/公司公告）

---

## 五步分析流程

### 第一步：数据采集（AKShare示例）

```python
import akshare as ak
from datetime import datetime

# 1. 获取最新财报（利润表）
df_income = ak.stock_financial_report_sina(stock="600519", symbol="利润表")

# 2. 获取资产负债表
df_bs = ak.stock_financial_report_sina(stock="600519", symbol="资产负债表")

# 3. 获取现金流量表
df_cf = ak.stock_financial_report_sina(stock="600519", symbol="现金流量表")

# 4. 获取业绩预告
df_forecast = ak.stock_yjkb_em(date="20260331")  # 最新季度预告

# 5. 获取一致预期（如可用）
df_consensus = ak.stock_a_lg_indicator(symbol="600519")

# 6. 获取当日估值数据
df_val = ak.stock_a_lg_indicator(symbol="600519")
```

**数据验证检查清单：**
- [ ] 财报日期确认为最新（与当前日期相差不超过3个月）
- [ ] 营收/净利润数据与官方公告核对
- [ ] 扣非净利润 vs 归母净利润差异确认
- [ ] 每股收益与股数对上（EPS = 归母净利润 / 加权股本）

### 第二步：业绩分析（Beat/Miss框架）

#### 核心指标比对表

| 指标 | 本期 | 上年同期 | 同比 | 上期 | 环比 | 一致预期 | 超/低于预期 |
|:---|:---|:---|:---|:---|:---|:---|:---|
| 营收(亿) | [A] | [B] | (A-B)/B | [C] | (A-C)/C | [D] | (A-D)/D |
| 归母净利润(亿) | | | | | | | |
| 扣非净利润(亿) | | | | | | | |
| 毛利率 | | | ±bp | | ±bp | | |
| 净利率 | | | ±bp | | ±bp | | |
| ROE | | | ±bp | | ±bp | | |

#### 分析要点

1. **营收** — 量价拆分：是量增还是价增？还是并购并表？
2. **净利润** — 非经常性损益排查（政府补贴/资产处置/公允价值变动）
3. **毛利率** — 成本端（原材料/运费/折旧）vs 价格端（提价/促销）
4. **费用率** — 销售/管理/研发/财务四项费用变化趋势
5. **现金流** — 经营现金流与净利润是否匹配（匹配度=经营现金流/净利润）

#### 红旗警示

- 🚩 净利润增长但经营现金流下滑（利润质量差）
- 🚩 毛利率同比大幅下滑且无合理解释
- 🚩 扣非净利润为负但归母净利为正（靠非经常性收益)
- 🚩 应收账款增速远超营收增速（回款恶化）
- 🚩 存货大幅增加且周转率下降（滞销风险）
- 🚩 商誉/无形资产占比>30%（减值风险）

### 第三步：核心财务健康检查

#### 资产负债质量

| 指标 | 公式 | 健康阈值 | 当前值 | 判断 |
|:---|:---|:---|:---|:---|
| 资产负债率 | 总负债/总资产 | 40-60% | | |
| 流动比率 | 流动资产/流动负债 | >1.5 | | |
| 速动比率 | (流动资产-存货)/流动负债 | >1.0 | | |
| 有息负债率 | 有息负债/总资产 | <30% | | |
| 商誉/净资产 | 商誉/归母净资产 | <20% | | |

#### 营运效率

| 指标 | 同期对比 | 趋势判断 |
|:---|:---|:---|
| 应收账款周转天数 | 上期=XX → 本期=XX | 改善/恶化 |
| 存货周转天数 | 上期=XX → 本期=XX | 改善/恶化 |
| 经营现金流/净利润 | 上期=XX → 本期=XX | 扎实/虚胖 |

### 第四步：业绩对估值的影响

1. **EPS更新** — 将最新财报数据代入，更新预测EPS
2. **PE rerating** — 业绩超预期→PE是否应该拔高？vs 透支
3. **DCF更新** — 调整自由现金流预测

**估值公式（当前）：**
```
PE(TTM) = 当前股价 / 最近4个季度EPS之和
PEG = PE(TTM) / (净利润增速% × 100)
```

### 第五步：输出结构

```
═══════════════════════════════════════════
[公司名称] [年份] [季度] 财报业绩更新
═══════════════════════════════════════════

一、核心结论 (1-2句， 超预期/不及预期)
二、业绩分析 (beat/miss 对比表)
三、财务健康 (资产负债+营运效率)
四、估值影响 (EPS更新+PE再评估)
五、风险提示 (红旗警示项)
六、数据来源 (AKShare调用记录)

═══════════════════════════════════════════
```
