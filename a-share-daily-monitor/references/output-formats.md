# 输出格式全文

## 输出格式

### 日报格式（15:45）
```
📊 A股持仓监控日报 | YYYY-MM-DD 15:45 CST

一、大盘环境
  上证: XXXX (+X.XX%) | 科创50: XXXX (+X.XX%)
  全市场估算成交额: X.XX万亿 | 达标判断

二、持仓快照
  标的 | 净值 | 日涨跌 | 偏离5MA | 偏离20MA | 回撤峰值 | 成本盈亏 | 信号

三、折溢价对照（市价 vs 净值）
  标的 | 市价 | NAV | 折溢价
  （免费源；不是券商「主力净流入」）

四、触发条件检查
  🟢 无触发 / 🔴 有触发(含动作建议)

五、外部变量
  美10Y / 中美利差

六、需要决策
  (仅触发时出现)
```

### 尾盘操作建议格式（14:50~15:00）

当用户需要尾盘决策时，先列出原始数据表，再给建议。用户说过"给我操作数据"——必须包含原始数据点：

```
⏰ 尾盘操作数据 — HH:MM

标的 XXXX

| 项目 | 数值 |
|-----|------|
| 当前价 | XX.XX |
| 今日高点 | XX.XX |
| 今日低点 | XX.XX |
| 昨收 | XX.XX |
| 涨跌 | X.XX% |
| 估算成本 | XX.XX |
| 浮盈 | +X.X% |

大盘背景
上证: XXXX (-X.XX%)
科创50: XXXX (-X.XX%)

操作判断
✅ 建议执行：卖一半 / 不动 / 挂限价
(1~2句话逻辑说明)

你选：
1. 今天直接卖一半
2. 挂XX.XX限价等明天
3. 不动
```

**核心原则：** 用户需要原始数据自己做判断，不要只有结论没有数字。先给数据表，再给建议。

### 大盘分析格式

当用户说"大盘分析"时——区别于"盘中分析"（聚焦持仓）和"早盘分析"（晨间脚本）。大盘分析是**全市场宽景扫描**：

**数据采集（必须全量）：**
1. 6大指数实时：上证、科创50、上证50、创业板、沪深300、中证500
2. 申万一级行业涨跌Top5（涨家Top5 + 跌家Top5）
3. 全市场涨跌家数（涨/跌/平比例）
4. 持仓标的实时价
5. 成交额Top10（判断资金流向）

**输出格式：**
```### 🌐 大盘全景 | YYYY-MM-DD HH:MM
上证  XXXX  +X.XX%  |  科创50  XXXX  +X.XX%
上证50  XXXX  +X.XX%  |  创业板  XXXX  +X.XX%
沪深300  XXXX  +X.XX%  |  中证500  XXXX  +X.XX%

### 申万行业Top5
涨: 行业A +X% | 行业B +X% | ...
跌: 行业X -X% | 行业Y -X% | ...

涨跌比: 涨N 跌M (X.XX:1)

### 🔥 核心变化：风格轮动（一句话）
上周是XX领涨，今天变成了XX领涨，XX在回调。

### 📌 你的持仓
（列表：标的/现价/涨跌/状态）

### 一句话总结
（1-2句定性结论）
```

**比盘中分析多做的：**
- 必须查申万行业数据（判断轮动方向）
- 必须输出涨跌家数比（判断市场宽度）
- 必须判断风格是否切换（成长→防御/防御→成长/主线延续）
- 成交额验证资金流向
