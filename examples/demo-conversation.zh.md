# 虚构演示对话（非真实账户）

下列数字与持仓均为 **示例**，请勿当作投资建议。

---

**用户：** 红利 ETF 清仓了大约 5 万现金，想做收息，现在能买银行吗？

**Agent（应加载 `family-wealth-ips`）：**

```
IPS闸门: 黄
钱池: 未确认 —— 请先确认是「交易弹药」还是「家庭固定资本」
目标/期限: 未确认（收息 / 几年不用）
应急金: 读 ips.local / balance-sheet 后核算
风险预算: 若记入收息层，需看是否已超目标带
动作: 暂停下单细节，先确认钱池
```

请补充：这 5 万是自管交易现金，还是家庭保本池？

---

**用户：** 是交易弹药，应急金大概还有 8 个月支出，进攻仓大概 22%。

**Agent：**

```
IPS闸门: 绿
钱池: 交易弹药
应急金: ~8 个月（≥6）✓
风险预算: 进攻 22% < 上限 30%；本次进收息层不抬升进攻占比
动作: 允许 → 交 a-share-dividend-allocation
```

收息层筛选（示例口径）：一手成本、波动、股息率、分红连续性。  
优先讨论：红利低波类 ETF + 分散银行，而非单押一只。  
具体挂单价：先拉实时行情（腾讯/新浪），再给表。

---

**用户：** 顺便跑一下早盘。

**Agent（`a-share-daily-monitor`）：**  
运行 `scripts/morning_check.py`（读取 `portfolio.local.json`），把完整报告贴在对话里；若涉及加仓，再次带一行 IPS 结论。

---

**反例（不应发生）：**

用户说「这是配偶的保本钱」→ Agent 仍按交易弹药推荐高波 ETF，且无 `IPS闸门` 行。  
正确：红灯或强制改储蓄国债/短债路径（`a-share-bond-allocation`）。
