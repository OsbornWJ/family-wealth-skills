# 限价单未成交应对框架

## 场景

用户挂了限价单（如创新药0.85买入600股），盘中价格短暂触及该价位但未成交（或用户没盯盘错过了），随后价格反弹。用户问：「挂不到咋办？」

## 核心区别 vs 错失买点

| | 错失买点 (missed-entry-chase-decision.md) | 限价单未成交 |
|:----|:----|:----|
| 问题根源 | 犹豫没买/没挂单 | 挂了但没成交/没盯盘 |
| 价格行为 | 价格一路上涨远离 | 价格短暂触及后弹回 |
| 用户心态 | 「后悔没买」 | 「挂了没到/没看到」 |
| 后续概率 | 可能继续涨 | 可能二次探底 |

## 诊断流程

### 第1步：确认价格是否确实触及过目标

```
查当日最低价 vs 挂单价
当日最低 = 0.843
挂单价 = 0.850
结论：最低价 < 挂单价 → 确实到过这个区域
```

- 最低价 < 挂单价 × 0.99 → **市场给了机会，只是没轮到你**
- 最低价 ≈ 挂单价（±0.3%）→ **碰到了但量不够，很正常**
- 最低价 > 挂单价 → **市场还没给机会，挂单仍在有效期内**

### 第2步：判断是「没到」还是「弹走了」

- **没到**（最低价 > 挂单价）：挂单继续有效，等
- **弹走了**（最低价 < 挂单价，但已反弹离目标 >2%）：进入第3步

### 第3步：弹走后怎么办 — 三选一

#### 选项A：等第二脚回踩（推荐）

价格在下跌后反弹，通常会有二次探底（double bottom）。尤其创新药这种波动大的品种：

特征：放量下跌→缩量反弹→二次缩量探底
这是最有可能给第二次买入机会的模式

```
第一次探底: 0.843  (放量)
反弹高点:  0.866  (缩量)  
二次探底预期: 0.84-0.86区间
```

**行动：挂单不动，等二次回踩确认。**

#### 选项B：微调价格重挂（次选）

如果二次探底幅度很浅（0.85以下只停了10分钟），可以微调价格到**阻力位上沿**（如0.855-0.860），但降低买入量：

```
原计划: 600股 @ 0.850
调整为: 400股 @ 0.855
```

原则：**价格越往上，买的量越少。** 不要因为错过了低价就全量追高。

#### 选项C：不补了（最安全的选项）

用户已经持有该标的，不是从零建仓：

```
持仓 9,800股 @ 0.9216 → 不补也不亏
如果涨了 → 9,800股跟着赚
如果跌了 → 现金等着，下次机会
```

**适用于：仓位≥5%时，不补也不是问题。**

## 原则总结

1. **限价单没成交是常态** — 不是操作失误。A股流动性不均，极限位往往只停留几秒到几分钟。
2. **弹走了就别追** — 股价不会因为你「差点买到」就等你。尊重市场的节奏。
3. **第二脚比第一脚更安全** — 大多数V型反弹都有二次探底，第二次的赔率更好（有前低做支撑位）。
4. **不补不是错过** — 已有仓位的人，错过加仓和踏空是两回事。

## 案例：创新药ETF 2026-07-01

```
用户挂单: 0.850 买入 600股
当日最低: 0.843（早盘9:30-10:00）
弹回至: 0.866（10:30后）

诊断: 弹走了，最低<挂单价，确实到过区域
建议: 选项A — 挂单不动等二次回踩
      或选项C — 已有9,800股，不补也可
结果: 用户选择等
```
