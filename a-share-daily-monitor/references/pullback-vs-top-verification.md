# 短期休整 vs 阶段见顶 — 五指标验证框架

当科技/成长股连续上涨后出现回调，用户问「这是回调还是见顶」时使用。

## 五指标诊断

### ① 量能分析（放量跌 vs 缩量跌）

```
放量跌（今日成交量 > 前5日均量 × 1.3）→ ❌ 偏空，有获利盘集中出逃
缩量跌（今日成交量 < 前5日均量 × 0.8）→ ✅ 健康回调，抛压衰竭
```

**注意区分 ETF 和个股的信号强度：**
- ETF 放量跌更值得警惕（机构行为）
- 个股放量跌可能是单一资金行为

### ② 日内振幅与位置

```
从最高点到收盘的回撤幅度：
< 3%  → 正常波动
3~5%  → 中等幅度的日内反转，需次日确认
> 5%  → 大阴线，警惕（如科创50 7/1 从2255→2140，回撤-5.1%）
```

**关键支撑位检查：**
- 是否跌破 MA5？→ 跌破 = 短期趋势转弱
- 是否跌破前一日最低点？→ 跌破 = 空头延续
- 收盘是否在当日最低点附近（下影线短）？→ 是 = 抛压未消

### ③ 风格轮动检查：钱走了还是搬家了

```
如果回调日同时出现：
✅ 防御品种（红利、公用事业）上涨
✅ 另一个成长板块（如医药）接力上涨
✅ 上证50 / 沪深300 稳定
→ 钱没离开市场，只是板块轮动，属于短期休整

如果回调日出现：
❌ 所有板块同步下跌，无一幸免
❌ 上证50 也大跌（>1%）
❌ 成交额极度放大
→ 系统性风险，需要重新评估
```

### ④ 大盘蓝筹（上证50）稳定性

```
上证50 跟跌 > 1% → 系统性风险，警惕
上证50 跟跌 < 0.5% 或平盘 → 非系统性，只是科技板块调整
上证50 上涨 → 完全正常的轮动，无需担忧
```

大盘蓝筹是市场的"压舱石"。大票不动 = 没出大事。

### ⑤ 次日确认信号（最关键）

单日回调不能定性，**必须看次日的走势确认**：

| 次日的走法 | 判断 |
|:----------|:-----|
| 缩量企稳（不破前日低点） | ✅ 短期休整确认 |
| 放量反弹收复大部分失地 | ✅ 洗盘结束，趋势延续 |
| 继续放量下跌，破前低 | ❌ 见顶概率大增 |
| 缩量小跌但站不稳 | 🟡 方向不明，再等一天 |

**核心规则：** 不在回调的第一天或第二天做重大决策。至少要等3个交易日才能确认趋势是否改变。

## 综合判定矩阵

| 信号 | 短期休整 | 阶段见顶 | 方向不明 |
|:----|:--------:|:--------:|:--------:|
| 量能 | 缩量 | 放量 | 量能持平 |
| 振幅 | <4% | >5%且收最低 | 中间 |
| 轮动 | 钱换板块 | 钱离场 | 不明 |
| 大盘 | 蓝筹稳 | 蓝筹跟跌 | 蓝筹微跌 |
| 次日 | 企稳/反弹 | 继续跌 | 方向不定 |
| **多数✅ → 休整** | | **多数❌ → 见顶** | |

## 实战案例（2026-07-01 科技回调）

**背景：** 芯片从1.638高点回落至1.533，科创50从2255回落至2140，连续两天下跌。

**五指标检查：**
| # | 指标 | 数据 | 信号 |
|:-:|:----|:----|:----:|
| ① | 芯片量能 | 548万手 > 前日466万手（放量） | ❌ 偏空 |
| ① | AI量能 | 270万手 < 前日428万手（缩量） | ✅ 健康 |
| ② | 振幅 | 科创50单日从高到低-5.1% | ❌ 剧烈 |
| ③ | 轮动 | 创新药+6.67%、红利+1.41% | ✅ 钱在搬家 |
| ④ | 上证50 | 2977 vs 2989（-0.4%）| ✅ 蓝筹稳 |
| ⑤ | 次日 | 早盘芯片-4.19%，科创50-3.08% | ❌ 继续跌 |

**结论：** 偏空信号（量/幅/续跌）vs 利多信号（轮动/蓝筹）= 3:2。暂判定为短期休整但幅度超预期，需要等第三天确认。

## 与「三问诊断框架」的关系

本框架是场景A（全市场急跌 - 三问诊断框架）的补充工具——
- 三问诊断框架：用于急跌当天的即时判断（是否恐慌、组合扛不扛得住）
- 五指标框架：用于急跌发生后的深度分析（到底是回调还是反转）

**使用场景区分：**
- 盘中急跌当天 → 用「三问诊断框架」（场景A）
- 连续回调2-3天后 → 用本框架做定性

## ⚠️ 利润安全垫调整（重要）

对于浮盈巨大的仓位（>50%），回调的容忍度应该更高：

```
浮盈50%+的仓位：回调10-15%都是正常波动，不触发任何卖出动作
浮盈100%+的仓位：回调15-20%都是利润回吐，不伤本金
浮盈200%+的仓位：回调20-30%仍然安全
```

**五指标框架中的偏空信号需要结合利润安全垫解读：**
- 浮盈薄（<20%）：放量跌3%就是实质损失 → 认真考虑减仓
- 浮盈厚（>50%）：放量跌5%只是利润回吐 → 不动，继续观察
- 浮盈极厚（>100%）：放量跌8-10%才需要关注 → 让利润奔跑

**脚本预警降级规则（2026-07-01实战教训）：** morning_check.py 等监控脚本的预警逻辑基于绝对涨跌幅（如-4%触发🔴），没有考虑浮盈安全垫。对于浮盈100%+的仓位，4~5%的日内回调只是利润回吐，不构成卖出信号。脚本预警在此情况下产生「噪音」，参考时应结合实际浮盈水平判断：
- 浮盈 > 50%：脚本预警降级为观察级，不操作
- 浮盈 20~50%：按规则处理但容忍度放宽
- 浮盈 < 20% 或浮亏：预警严肃对待
**浮亏 > 10%：预警升级，检查止损线

### ⑥ 条件单纪律：恐慌中不下调

当用户问「我要改第一档加仓吗，下调？」时：

**规则：不改。** 理由：

1. 条件单的间距已经留够了安全垫（AI从1.324高点→1.17第一档 = -11.6%）
2. 如果1.17都不敢买，当初为什么设这个条件单？
3. 下调条件单 = 在恐慌中把买入价调低，等于赌科技崩盘——这和用户的「纪律性激进」原则相悖
4. 加权成本计算可见：条件单全部触发后，原仓成本0.5138→新加权成本0.886，依然有33%的浮盈空间（以1.182计算）

**替代方案：** 如果实在担心，可以减半该档加仓股数（如3,000改为1,500），但不改价格。保持「价格到了就买」的纪律，而不是「价格到了我怕了」。

**核心原则：** 条件单的意义就是在恐慌时帮你按纪律执行。市场正在考验你的纪律——不要让情绪驱动决策。**

**战例参考：** 2026-07-02科技暴跌日（芯片-8.8%，AI-8.0%），AI距第一档1.17仅差-1%。用户选择维持条件单不动。次日7/3 AI+0.59%企稳，验证了「不改条件单」的正确性。`
