# A股独立于美股行情 — 脱钩分析

## 场景

美股隔夜大跌（-2%~-5%），但A股次日低开高走甚至翻红。用户惊讶地问「美股跌了A股没跟，怎么回事？」

## 核心诊断框架

### 第一步：检查A股领涨板块

美股大跌次日A股的表现取决于**跌的原因**：

| 美股跌的原因 | A股反应 | 案例 |
|:-----------|:-------|:-----|
| 美国自身因素（就业/CPI/科技股业绩） | 低开0.5~1.5%后回拉，甚至翻红 | 2026-06-24：美股盘前科技跌→A股科创50+3.11% |
| 全球性风险（地缘政治/油价/疫情） | A股也会跌，跟跌幅度更大 | 需区分 |
| 美联储政策紧缩预期 | 科技低开，建行/红利可能受益 | FOMC周模式 |

**核心观察：当美股跌是"美国自己的问题"时，A股反而可能吸引外资流入（美元弱→人民币强→外资买A股）。**

### 第二步：检查汇率和外资

```
美股暴跌 + 人民币没贬值 = A股没问题
美股暴跌 + 人民币大幅贬值 = A股也要小心
```

2026-06-24模式：FOMC偏鸽→美元走弱→人民币走强→外资流入A股科技→科创50+3.11%。

### 第三步：检查A股自身趋势

```
A股已经走独立行情了吗？
科创50 在美股跌之前已经在涨 → 大概率继续涨
科创50 也在跌 → 美股下跌是雪上加霜
```

## 输出格式

当用户说「美股跌了A股居然没跟」时：

```python
诊断：
  美股跌的原因：[美国自身/全球风险/政策]
  A股跟跌幅度：[0~0.5%不跟 / 0.5~2%跟随 / >2%同步]
  领涨板块：[科技/防御/普跌]
  汇率方向：[人民币升/贬/平]

结论：
  [不跟 → A股独立行情，继续按A股自身逻辑做]
  [跟一部分 → 中性，等开盘确认方向]
  [跟跌 → 系统性风险，减仓防御]
```

## 案例：2026-06-24（连续3天）

```
美股盘前-3%~-5%（科技领跌）
A股开盘：上证仅-0.16%，科创50+1.36%
收盘：科创50+3.87%，芯片+5.04%，AI+3.56%

诊断：
  原因：FOMC偏鸽→美元弱（美国自身因素）
  跟跌：几乎不跟（0~0.5%）
  领涨：科技全线（芯片/AI/创新药）
  汇率：人民币走强
结论：A股独立行情，外资流入A股科技
```

## 关键区别

| 美股跌 | A股反应 | 操作 |
|:------|:--------|:-----|
| 纳斯达克科技股领跌 | 低开0~1%，迅速回拉 | 不操作，科技继续持有 |
| 道指工业股领跌 | A股上证跟跌0.5~1% | 偏防御，观察 |
| 全市场-3%+系统性 | A股跟跌1~2% | 检查条件单是否触发 |
| 美股+美债+商品三杀 | A股跟跌2%+ | 警惕系统性风险 |
