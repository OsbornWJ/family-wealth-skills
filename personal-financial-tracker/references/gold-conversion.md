# 黄金价格单位换算与参考数据

## 核心换算公式

```
RMB/克 = USD/盎司 ÷ 31.1035 × 美元兑人民币汇率
USD/盎司 = RMB/克 × 31.1035 ÷ 美元兑人民币汇率
```

## 操作框架

### 什么时候该卖？

- **回本价附近**（4,900~5,000$/oz）：可以卖一半回收现金，等回调再买入
- **金价急涨偏离均值+10%**（如5,400$/oz以上）：考虑止盈，锁定利润
- **仓位占比过高**：占总资产>30%时即使浮亏中，也在回本时减仓至20g

### 什么时候该买？

- **金价跌破4,000$/oz**（约926元/g）：全球恐慌级，可考虑加仓5~10g
- **金价在4,200$/oz以下缩量企稳**：中等买点
- **当前（4,500$/oz）**：不上不下，不买不卖

### 什么时候不动？

- 4,400~4,800$/oz 区间内震荡 → 不动
- 亏损-10%以内且仓位占比<30% → 不动（黄金的正常波动范围）

## 关键参考

- 全球央行购金趋势：中国央行连续20个月+增持黄金储备
- 美债利率 vs 金价负相关：美10Y>4.5%时金价承压
- 避险需求：地缘冲突（俄乌、中东、台海）推升金价
