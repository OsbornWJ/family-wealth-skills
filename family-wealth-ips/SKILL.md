# 家庭理财约定（出手前先问清楚）

一句话：**还没想清楚「这是哪笔钱、家里能不能扛」之前，不要推荐买什么。**

（业内常叫 IPS / 投资政策说明书；这里就叫「家庭理财约定」。）

本 skill 优先级最高。只要涉及买卖或配置，先做下面的「能不能买」检查。过不了 → 只说明卡在哪、还缺什么信息，**禁止直接荐股或替用户下单**。

看盘、收息、买债等细节交给后面的 skill；本 skill 只回答三件事：

1. **该不该动**  
2. **动的是哪一笔钱**  
3. **股票类仓位会不会超标**

## 什么时候用

- 用户说：买、卖、加仓、减仓、清仓、换仓、定投、「钱放哪」
- 提到：家里保本的钱、应急金、教育/养老/买房
- 问：家底多少、还能不能加风险、仓位是不是太高
- 金额较大（超过家里活钱大约 5%），或要动配偶/家人的钱

**可以跳过的情况：** 只是聊行情、明确说不操作 → 可直接看盘；但一旦说到「要不要买」，仍要先问清楚。

## 出手前检查清单（每次建议前）

按顺序过一遍；有一项不过关 → **先别买**：

| # | 问什么 | 怎样算过关 | 不过关怎么办 |
|:---:|:---|:---|:---|
| 1 | **这是哪笔钱？** | 已分清：自己炒股的钱 / 家里保本的钱 / 债基蓄水池 / 家人名下的钱 | 先问清楚，别默认当成炒股的钱 |
| 2 | **这笔钱打算干什么、多久不用？** | 用途和年限清楚（或用户说可以长期扛波动） | 先问目标，别急着推产品 |
| 3 | **应急金够不够？** | 活钱+短债 ≥ 大约 **6 个月**生活费（见 `assets/ips.local.md`） | 先留够吃饭的钱，再谈加仓 |
| 4 | **股票类会不会买太多？** | 买完后「进攻/股票类」占比 ≤ 约定上限；单只也不超上限 | 少买一点，或这次不买 |
| 5 | **是不是配偶/家人的钱？** | 若是：已提醒可能影响关系，且方案偏保本 | 默认不推高风险，除非用户明确同意 |
| 6 | **大病/房贷这些扛得住吗？** | 知道有没有大缺口（不知道就写「还没核对」） | 大额加仓前先提醒核对保险/负债 |
| 7 | **是不是某类已经买超了？** | 若某层已经超目标，先调结构 | 先减超配，再谈新主题 |

说完建议时，必须有一行白话结论，例如：

**`能不能买：可以 / 先少买点 / 先别买`** + 哪笔钱 + 股票类大概占多少。

## 「哪笔钱」怎么分

| 叫法 | 这笔钱要什么 | 亏多少受得了 | 适合放什么 |
|:---|:---|:---:|:---|
| 自己炒股的钱（交易弹药） | 尽量抓住机会 | 能接受波动 | 货基/短债待命；股票按交易规则 |
| **家里保本的钱** | **本金安全 > 吃点息 > 想赚更多** | **几乎不能亏** | 储蓄国债、短债、存款；**默认别买**高波动股票/题材 ETF |
| 债基蓄水池 | 钱暂时停靠 | 很小回撤 | 已有短债/债基，一般维持 |
| 家人名下的钱 | 关系更重要 | 看家人 | 只能给建议；场外定投优于一把梭 |

钱分错了 = 整单建议作废。

## 家里的默认规矩（数字在 assets 里改）

具体数字以 [`assets/ips.example.md`](assets/ips.example.md)（复制为 `ips.local.md` 后填写） 为准；没填就用下面默认：

| 规矩 | 默认 | 人话 |
|:---|:---:|:---|
| 应急金 | 6 个月开支 | 至少留够半年生活费的活钱 |
| 股票类上限 | 家庭金融净资产的 25–30% | 别把大部分家底押在股市 |
| 收息层 | 大约 25% | 银行、红利低波这类 |
| 固收+现金 | 至少 40% | 保本和停靠的钱要够 |
| 单只上限 | 15% | 别单押一个品种 |
| 偏离太多 | 目标 ±5 个百分点 | 先调仓，再追新热点 |

## 建议怎么说（给用户听得懂的格式）

```
能不能买: 可以 | 先少买点 | 先别买
这是哪笔钱: …
这笔钱打算: …（用途/多久）
应急金: 大约 X 个月（缺不缺…）
股票类仓位: 现在约 Y%，上限 Z%，这次买完大约 W%
接下来: 可以买 / 少买 / 先别动
一句话原因: …
（只有「可以」或「先少买点」时）再谈具体买什么 → 交给收息/债/看盘等 skill
```

- **可以** = 检查都过了，可以谈标的  
- **先少买点** = 能买但要缩量或加条件  
- **先别买** = 本次不要给下单指令  

## 大额加仓前多想一眼

见 [`references/stress-checks.md`](references/stress-checks.md)。至少说一句：

- 股市再跌 20%，会不会动到家里保本的钱？  
- 万一半年没收入，应急金还够不够？  
- 债也亏的时候，家里固收放得是不是太长久期？

## 常见坑

1. 今天跌得多就动用「家里保本的钱」去抄底——不行。  
2. 用户说「止盈」不一定等于清仓；算占比要用真实还持有的仓。  
3. 别把证券账户里的可用资金和家底表里的现金加两遍。  
4. 没读 `ips.local.md` 就报目标比例——先读文件。  
5. 即使用户说「你定/少问我」，也**不能**跳过「哪笔钱」和保本钱禁投。
