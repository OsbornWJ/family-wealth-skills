# 战术T出框架 — 加仓部分卖出决策（加仓的T出去）

## 触发条件

用户问「上次加仓的T出去」「加仓的部分要不要卖」「先T一部分」等——用户想卖出**战术性加仓部分**（博前低/补仓/抄底买入的仓位），保留核心底仓不变。

**与止盈的区别：** 止盈=全部或一半仓位卖出锁利。T出=只卖战术加仓部分，核心仓位继续持有。

**与减仓的区别：** 减仓=降低总仓位。T出=仓位结构不变，只是卖出短期博利润的部分。

## 前置数据确认

```
用户持仓：
- 核心底仓：X股 @ 成本A
- 战术加仓：Y股 @ 成本B（某次补仓/博前低）
- 加权均价：Z = (A×X + B×Y) / (X+Y)

T出后变化：
- 卖出Y股 → 剩X股 @ 成本A（回到核心底仓成本）
- 现金回笼：Y × 当前价
- T出锁利：Y × (当前价 - B)
```

第一次回答**必须**从memory读取加仓记录（成本+股数+日期），不要猜测。如memory无记录则问一次，不答则出通用计算式。

## 三步决策

### 第1步：检查T出收益率

| 收益率 | 判断 | 行动 |
|:-----:|:----|:----|
| >+8% | 🟢 适合T | 可以执行，锁定利润 |
| +3%~+8% | 🟡 可等可做 | 当前价可T，但建议等更高 |
| 0%~+3% | 🟠 太薄 | 不够手续费+心理差价，等反弹 |
| <0%（浮亏） | 🔴 不T | 战术加仓变套牢，按持仓止损线处理 |

### 第2步：判断时机（盘中or尾盘）

| 位置 | 判断 | 建议 |
|:----|:----|:----|
| 价格在日内低位（下1/3区间） | 尾盘砸出来的 | 今天不动，等反弹 |
| 价格在日内中位（中间1/3） | 正常波动 | 可T可等，看用户意愿 |
| 价格在日内高位（上1/3） | 反弹高点 | 直接T出锁定 |

检查方法：对比当前价 vs 当日最高/最低。

### 第3步：综合输出

```
### 战术T出方案

**加仓记录：** [日期] +[Y]股 @ [B]
**现价：** [当前价]

| 项目 | 数值 |
|:--|:--:|
| 加仓成本 | B |
| T出价 | 当前价 |
| 差价 | +X% / -X% |
| 锁利金额 | ¥X |
| 回笼现金 | ¥X |

**T出后持仓：** 剩X股 @ 成本A

### 判断
[结论，如：今天不动等反弹/直接T/继续持有]

**如果今天要T：** [时机建议]
**如果不T：** [目标价位建议，如"等反弹到X.XX以上再T"]
```

## 2026-07-08实战案例

用户问「上次加仓的T出去」指7/2科技暴跌日买的600股创新药@0.823。

当前价0.901，T出收益率+9.5%。但尾盘价格0.901已接近日内最低0.900。

**判断：** 今天不动等反弹。现价接近全天低点，不是好T出价。明天反弹到0.92-0.93再T，差价能多一倍。

**结果：** 用户接受建议，等反弹再T。

## 注意事项

- T出不等于止盈——核心底仓不动，只卖战术部分
- T出的资金可以重新等待下一次加仓机会（不是离开市场）
- 如果战术加仓后标的连续大跌，T出亏损→说明时机判断错了，该仓位转为长期持有或等反弹再T
- 不要为了T而T——如果T出只能赚一顿饭钱（<¥50），等个好价格再出手
