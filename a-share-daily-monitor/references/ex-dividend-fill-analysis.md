# 除息填权分析 — 建行范例

## 用户常见问题

**用户问：建行为什么除息完还有这么多资金进入？**

### 核心概念

除息 = 公司把利润分给股东，股价相应下调（除息价 = 前收盘 - 每股分红）。
填权 = 除息后股价上涨，补回除息缺口。

### 除息日仍有资金买入的原因

1. **填权行情启动了**：除息后开盘价低（如建行7/13开盘9.72），对收息资金有吸引力。市场认为分红后价值不变，买入填平缺口。

2. **股息率重新变得有吸引力**：
   | 时间 | 价格 | 股息率 |
   |:---|:---:|:-----:|
   | 除息前 | 10.03 | 3.87% |
   | 除息后开盘 | 9.72 | **4.00%** |
   | 填权中 | 10.12 | 3.84% |
   
   除息后开盘股息率重回4%+，对保险资金/社保/养老金是买入信号。

3. **大盘弱势时资金涌入银行避险**：科技回调时，银行股是高股息+低波动的避风港。建行除息日成交额可达平时的2-3倍。

4. **机构调仓**：7月是机构调仓期，银行股是底仓配置首选。

### 对用户持仓的影响

- 用户2000股建行，分红约¥405.8（税前），除息后持仓市值不变（价格下调+现金入账）
- 如果用户计划除息后补仓：需关注填权速度。快速填权则补仓价可能高于预期（如计划9.30-9.50但实际10+），需调整计划
- 3.5%股息率阈值对应价位11.11元——当前远低于此，安全

### 计算

```
建行2025分红：0.3887元/股（年报0.2029 + 中报0.1858）
除息基准价 = 登记日收盘价 - 0.3887

用户2000股分红 = 2000 × 0.3887 = ¥405.8（税前）
税后（10%红利税，如持股>1年免）≈ ¥405.8（免）或 ¥365.2（非免）
```
